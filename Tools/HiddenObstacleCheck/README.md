# Hidden obstacle core checks

Run `dotnet run --project Tools/HiddenObstacleCheck/HiddenObstacleCheck.csproj` from the Unity project. No Unity process or packages are required.

HID-01 checks actual Press/Advance motion, all five warning delays, swept real collisions and landing rewards, body postponement and departing/returning contact, pause/countdown/retry, independent forecast state, 2–4-player array permutations under both camera types, terminal participants, airborne players, bonus-driven reveal crossing, visible gates and unchanged hidden metadata on old tracks.

The 5.4.1 extension retains the original 13 scenario groups / 1005 assertions and adds mixed authored leads/durations on one shared timeline, first-player and source-order checks, exact deadlines, elapsed-based progress with pause/postponement/retry, independent cloned forecasts, metadata validation and null defaults on all seven existing full tracks. `Obstacle.HiddenRevealDistance` must be finite and positive; `HiddenWarningDuration` must be finite and greater than 1/240 s. Invalid authored values throw instead of being clamped. Null uses 440 units and the selected global warning. Public `RevealDistanceFor`, `WarningDurationFor` and `WarningProgress` expose effective timing; progress reaching one does not change a postponed stone's Warning phase.

Tracks containing hidden ordinary stones use adaptive shared steps. Future warnings cut at their exact deadline; unrevealed stones bound a slice by their effective warning duration so a newly started timer cannot also expire inside that slice. Only an overdue occupied warning needs the 1/240 s body-clear sampling bound (lag up to 4.167 ms). All-solid worlds use ordinary analytic steps. Reveal is observed at the exact crossing inside existing analytic movement segments, reducing candidates by timestamp and then player ID. Core motion, collisions, landing planes, rewards, recovery and legacy track stepping retain the existing analytic implementation. Visual acceptance and the exported build are separate checks.
