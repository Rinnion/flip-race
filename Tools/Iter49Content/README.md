# ITER49 content proof

Run from the Unity project root:

    dotnet run --project Tools/Iter49Content/Iter49Content.csproj

Final source uses actual production IsCoin/CoinsEarned/LastCoin and the shared public Press/Advance scheduler. It does not inject player state or use passive candidate probes. It writes only Verification/iter49-03-content.json/.txt (stdout can be piped to Tee-Object).

The 282 games comprise144 real Mixed route games (four coin subsets, four new-negative subsets, four existing-negative subsets; each with both profiles and six step sizes),48 identical-timestamp no-coin counterfactuals and90 isolated games including12 real rematches. Every Mixed route preserves nine ordinary rewards and the complete finish pulse; coin branches avoid all four negatives. Each new trap has a real collision-free route, including the branch taking both.

Geometry compares the immutable stage01 capture. Original obstacles are hashed without normalization. Original risk zones exclude exactly four named additions and only the newly introduced computed IsCoin JSON property; every original field is still compared. Do not regenerate Verification/iter49-01-before.json.

Isolated cases prove personal later/simultaneous collection, max2 with a real third contact, unequal coin counts cannot break a physical tie, rematch and after-result behavior, continuous circular contact/tangency/outside misses, exact active/queued effect identity, impact/recovery and an active finish pulse. Every new game starts through real ready/countdown actions. Source hashes are verified unchanged during the run.

PREP artifacts are historical observations before IsCoin existed. They used clone-only positive contacts with ClearX9000 so the production continuous contact solver could record personal IDs without ever serving a reward. Those probes were not final coins and are not present in final source or final proof.

Rendering, coin PNG cleanup/resources, actual shared/split visual availability and the final WebGL/ZIP acceptance are the parent's separate integration checks. The pure Core personal availability state is verified here.
