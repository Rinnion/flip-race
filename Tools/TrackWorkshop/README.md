# Мастерская трасс 0.5.16

В 0.5.16 у коротких интервалов после посадки можно проверить более позднее нажатие: от настраиваемого порога (исходно 200 мс), с шагом 50 мс. Показаны успешные проверенные варианты, изменение времени финиша и их траектории; доступен возврат к исходному прохождению. Остальные нажатия сохраняют прежнее время.

В 0.5.15 поиск показывает оценочный процент выполнения и текущий этап. Индикатор получает прогресс от сервера; 100% появляется после применения итогового результата. Отмена или ошибка не считаются завершением.

В 0.5.14 результаты анализа показываются только для текущего полного набора настроек. В JSON они разделены на группы `settings` → `runs`; поиск сохраняет остальные группы, в том числе варианты того же управления с другим разгоном. Старый анализ преобразуется при следующем поиске.

В 0.5.13 общий блок «Настройка забега» задаёт управление, предупреждение и разгон для воспроизведения, живого пробега и поиска. Новая сессия использует основной игровой пресет разгона. Подготовка бота отдельно показывает совместимость игрового экспорта и пробу Мастера с выбранными настройками.

В 0.5.12 добавлен поиск вариантов прохождения с шагом решений 100 мс. Блок «Анализ трассы» сохраняет до 1000 лучших найденных лент в JSON карты, сортирует их по времени финиша и позволяет выбрать источник траектории. Короткие интервалы после посадки отмечаются на выбранном маршруте; исходный порог — 200 мс.

В 0.5.10 рассчитанная траектория остаётся на схеме после правок и помечается как предыдущая. Кнопка над обзором скрывает или возвращает линию на обеих схемах. Для воспроизведения после правки нужен новый расчёт.

## Редактирование уровня

В 0.5.9 мастерская получила новую компоновку. «Новый уровень» открывает создание пустой трассы; название, идентификатор и длина доступны отдельными полями. Меню «Файл» содержит встроенные трассы, открытие JSON с диска и скачивание. Встроенная трасса открывается как копия с собственным ID; оригинал в каталоге не перезаписывается.

Слева находятся вертикальная палитра и построчный редактор свойств выбранного объекта. Корректная правка обновляет схему после проверки Unity; ошибочная остаётся в поле с объяснением. Дополнительная вкладка JSON сохраняет доступ к полному объекту. Общий JSON трассы перенесён вниз и по умолчанию свёрнут. Все типы палитры, однократное размещение, отмена и повтор сохранены.

## Живой пробег из редактора

С 0.5.8 клавиша **R** перезапускает живой пробег с той же выбранной точки и сразу запускает движение после восстановления состояния сервером. Нажимать «Начать отсюда» больше не нужно. Префикс сохраняется, новое продолжение очищается; лишнего прыжка не происходит. При X=0 сохраняется обычный отсчёт. Первое открытие выбранного участка и кнопка «Заново» оставляют готовую паузу. Удержание R даёт один перезапуск. При потере фокуса во время подключения автозапуск отменяется: нужно явное продолжение. В редакторе, полях ввода и сочетаниях Ctrl/Alt/Meta+R команда не срабатывает; физическая клавиша не зависит от раскладки.

В 0.5.6 можно выбрать место старта на подробной схеме или обзоре либо ввести X числом. Маркер обозначает координату центра героя; высота щелчка не задаёт положение тела. «С начала» возвращает обычный старт. Выбор не меняет JSON или историю редактирования, а открытие другой трассы сбрасывает маркер.

До выбранного места мастерская быстро воспроизводит текущий список нажатий через Core. Пустой список означает движение без действий. Получается настоящее состояние попытки: полёт, скорость, восстановление после удара, собранные награды и таймеры скрытых камней сохраняются. Показываются выбранный и фактически достигнутый X; передача происходит на ближайшей достигшей места границе обычного шага, без переноса на безопасную опору. Нажмите «Начать отсюда», когда будете готовы. Оставшаяся часть исходного списка автоматически не проигрывается.

«Заново» восстанавливает тот же участок и готовую паузу. Сохранение нажатий включает исполненную часть прежнего списка и новые живые действия в секундах от начала полной трассы. Такой список можно воспроизвести и использовать для подготовки бота обычным способом. Итоговые время/удары/награды включают пройденную часть; лимит 120 секунд также остаётся общим. Недостижимая точка и ошибочный список объясняются без скрытого перехода к началу.

В 0.5.5 после паузы или окончания попытки можно сохранить её нажатия в список редактора. Команда «Сохранить нажатия в редактор» заменяет прежний список и выбирает режим «по времени»: записываются точные игровые секунды подтверждённых действий, включая отклонённые. Обычный возврат через «В редактор» оставляет список прежним. «Заново» начинает новую запись. После переноса нажмите «Построить траекторию» либо «Подготовить бота»; исходный JSON трассы сохраняется.

После паузы кнопка ждёт ответы на уже отправленные команды. При ошибке соединения доступна подтверждённая часть записи; неполученные и недостигнутые нажатия не включаются. Пустую запись сохранить нельзя. Предел — 4096 нажатий: превышение явно блокирует перенос без обрезки. Если сохранить незавершённую попытку, проверка траектории продолжит её оставшуюся часть без новых действий.

Для подготовки бота список по времени сначала воспроизводится через Core. Координаты принятых действий становятся подсказкой поиска; совпавшие координаты не дублируются. Исходный список секунд не меняется, а полученный маршрут проходит обычную проверку эталона и настоящего Мастера. Запись человека сама по себе не гарантирует готового бота.

Откройте трассу и дождитесь успешной проверки JSON. Выберите управление и предупреждение, затем нажмите «Играть». Откроется отдельное поле с кругом реального размера героя. После отсчёта он бежит автоматически; A, пробел или кнопка прыжка/переворота подают действие в тот же C# Core, который рассчитывает проверку нажатий. Удержание не создаёт повторов.

Камера следует за героем без выбывания за левый край. Доступны пауза, продолжение, новая попытка и возврат в редактор. При потере фокуса или скрытии вкладки пробег автоматически приостанавливается; продолжение требует явного действия. При потере связи движение не продолжается локально. Финиш и предел 120 секунд активного прохождения останавливают попытку.

Пробег использует снимок текущего корректного JSON, выбранный Основной/Быстрый переворот и таймер предупреждения. Ограничение chosen-only и индивидуальные authored-таймеры сохраняются. Пока пробег открыт, редактирование заблокировано. Возврат сохраняет исходный JSON, список нажатий, историю и настройки редактора. Живые нажатия не подменяют авторский список. Ошибочный полный JSON или неприменённая правка объекта не позволяют запустить старую схему как новую трассу.

Для живого режима требуется постоянное WebSocket-соединение с тем же сервером мастерской. В штатном серверном пакете его обслуживает существующий защищённый Caddy reverse proxy; отдельный порт открывать не нужно. Высокая задержка сети может остановить пробег на паузе. Длительное бездействие или ограничение времени сессии завершает соединение; новую попытку можно запустить заново.

## Редактирование трассы

Кнопка палитры сразу включает размещение выбранного типа. Один щелчок на подробной схеме создаёт объект и возвращает навигацию/редактирование. Повторное нажатие той же кнопки без размещения выключает режим; другая кнопка меняет размещаемый тип. Esc и «Отмена» также отменяют размещение. Подсвечена только кнопка активного размещения; в обычном режиме все кнопки отжаты. Кнопка «Скрыть JSON трассы» освобождает ширину для схемы; «Показать JSON трассы» возвращает исходник.

## Нумерация выпусков

По прямому указанию пользователя от 6 ноября 2026 **каждая доработка мастерской получает новый номер версии**, включая небольшие изменения интерфейса. Номер в шапке, footer, /healthz, csproj, launchers и именах пакетов должен совпадать. Уже выпущенные ZIP не заменяются новой доработкой под прежним номером.

В 0.5.2 JSON выбранного объекта можно редактировать прямо под схемой. После короткой паузы мастерская проверяет весь получившийся документ загрузчиком Unity и автоматически обновляет карту и полный JSON. Остальной текст документа сохраняется. Ошибка синтаксиса, недопустимый параметр или нарушенная связь показываются рядом с полем; набранный текст остаётся доступен для исправления, а карта сохраняет последний корректный вариант. Можно явно сбросить неприменённую правку. До исправления или сброса конкурирующие визуальные правки недоступны.

Применённые изменения входят в историю отмены/повтора и автосохранение трассы; прежние траектория и подготовленный результат становятся неактуальными. Внутри текстового поля Ctrl+Z остаётся обычной отменой ввода. Неприменённый ошибочный фрагмент не заменяет сохранённую трассу. Редактирование фрагмента имеет те же правила, что и полный JSON: связанные объекты не перестраиваются автоматически, а нарушение ссылок отклоняется проверкой. «Выделить JSON» выделяет весь фрагмент для копирования.

Отдельный инструмент для JSON-трасс Flip Race Unity, schemaVersion 1 / physicsVersion 1. Для импорта подготовленного файла с ботом нужна игра **5.4.4**: она независимо проверяет маршрут и Мастера перед допуском BOT. Мастерская не перезаписывает файлы игры. Для локального пакета нужен установленный .NET 8 (для исходников — SDK, для готового пакета — ASP.NET Core Runtime 8 либо SDK 8). Серверный Docker-пакет содержит ASP.NET 10 LTS и не требует установки .NET на хосте.

Для локальной работы запустите `Start.cmd` или `Start.ps1` и откройте [мастерскую](http://127.0.0.1:4186/). Окно сервера оставьте открытым; Ctrl+C его останавливает. Запуск работает из любой текущей папки. По умолчанию сервер слушает только 127.0.0.1:4186; на внешний сервер данные не отправляются.

Серверный выпуск поставляется отдельным ZIP: в корне находятся Dockerfile, compose.yaml, Caddyfile, .env.example и пошаговый README.md, а в app/ — готовое приложение. Он рассчитан на отдельный домен, HTTPS и вход разработчика по паролю; публикация только содержимого Web/ не выполняет расчёт траекторий. При сетевом использовании JSON и нажатия передаются серверу для проверки и расчёта. Пользовательские файлы не сохраняются на сервере: открыть/скачать их позволяет браузер. Редакторы разных людей независимы; общей библиотеки и совместного редактирования нет.

Выберите встроенную трассу либо откройте свой JSON. Для создания выберите тип в панели добавления и щёлкните на подробной схеме. Для посадочной метки или связанного бонуса сначала выберите нужное препятствие; посадка требует именно камень. Новые объекты получают уникальные ID. Встроенные файлы не перезаписываются.

Щёлкните объект, чтобы выбрать его. Тяните сам объект для перемещения, а появившиеся ручки — для изменения размеров. JSON обновится после отпускания мыши. Пустое место схемы, либо Alt/пробел при перетаскивании, двигает обзор. Камни сохраняют стену; ворота — обе части и смещения; посадка остаётся на поверхности камня. Размер финишных стрелок фиксирован физикой игры, поэтому ручек размера у них нет.

Кнопка удаления или Delete вне текстового поля удаляет выбранный объект. При удалении препятствия удаляются и связанные награды; число объектов показано заранее. Если удалён последний скрытый камень из карты с авторскими таймерами, предупреждения переключаются в обычный режим с уведомлением. «Отменить» и «Повторить» возвращают визуальные действия; Escape отменяет незавершённый жест/добавление. Ручная правка JSON или открытие другого файла сбрасывает визуальную историю, чтобы она не затирала новый текст.

Схема использует физические полосы обеих частей ворот, формы финишных стрелок и реальное окно посадочной метки. Это техническое представление координат, а не художественная версия игры. X направлен вправо, Y вниз; коридор 240, радиус героя 14.

Для траектории выберите Основное (Chosen) или Быстрый переворот (FastFlip), длительность предупреждения и список нажатий. Явно выберите единицы: координаты X центра героя или секунды после конца отсчёта. Данные эталона встроенной трассы можно использовать как готовый пример. Вычисление выполняется настоящими production Press/Advance в одном SOLO с камерой, следующей за героем; выбывания за экраном нет. Это не полная симуляция гонки нескольких игроков: их тела и будущие нажатия могут менять безопасное раскрытие скрытых камней.

Отчёт различает принятые, проигнорированные и недостигнутые нажатия; показывает удары, награды, скрытые состояния и фактическое время. Линия пути дискретизирована не реже 120 раз/с, точные точки ввода добавляются отдельно. Метки событий наблюдаются на ближайшем шаге (до 1/120 с); их положение не выдаётся за точную точку контакта. Коллизии вычисляет движок аналитически. Предел: 120 секунд и 4096 нажатий; неверный JSON и ограничения профиля сообщаются явно.

После редактирования геометрии прежние botReferences обычно устаревают. Предпросмотр явно сообщает, если проверка эталонов не прошла, и вычисляет копию без них. Проверка не переписывает исходный текст. Обычная кнопка скачивания позволяет экспортировать проверенный JSON без устаревших эталонов для человеческих режимов. «Скачать исходный текст» сохраняет точный текущий текст, включая ошибки. Просмотр нажатий старого эталона не создаёт новый; валидный хеш сам по себе не доказывает проходимость.

## Подготовить карту для бота

1. Откройте или отредактируйте JSON и дождитесь проверки. Выберите ниже готовое управление: Основное (`Chosen`) или Быстрый переворот (`FastFlip`). Ограничение `chosen-only` сохраняется. Мастерская готовит текущий выбранный профиль; для второго профиля можно выполнить отдельный запрос через API.
2. Проверьте «ID подготовленной трассы». Для встроенной карты заранее предложен `custom-<исходный-id>` и показано «Будет создан новый ID для импорта». ID можно изменить. Встроенные и исторические ID зарезервированы; повторный импорт уже занятого пользовательского ID игра также отклонит. Сервер не знает каталог другой игровой сессии и не гарантирует глобальную уникальность ID.
3. Нажмите «Подготовить бота». Находится хороший чистый маршрут с совместимыми наградами и полным финишным рывком, затем проверяются эталон и настоящий Мастер. Ручной список X, если он корректен, служит необязательной подсказкой; новый поиск работает и без него. Ввод по времени подсказкой поиска не является. Кнопка «Отменить поиск» прерывает запрос.
4. Результат показывает профиль, выбранные IDs наград, время эталона и статус проверки Мастера; найденный путь показывается обычным проигрывателем. Исходный JSON и ручной список нажатий остаются прежними. Поиск не обещает оптимум или сбор всех альтернатив. Изменение исходного JSON, управления, предупреждения или выходного ID сбрасывает результат.
5. Нажмите отдельную кнопку **«JSON для игры с ботом»**. Этот файл содержит новый ID копии и проверенные `botReferences`; обычное скачивание исходника его не заменяет. В игре 5.4.4 откройте «Выбрать трассу» → «Импорт JSON» и выберите файл, затем подготовленное управление. Карта сразу доступна людям; BOT включается только после независимой проверки выбранного профиля в игре. Импорт и допуск живут до перезагрузки игровой страницы.

Нужны хотя бы одно логическое препятствие (`C > 0`), ровно одна финишная цель с полным эффектом и допустимое соотношение пользы/стоимости `B/C` существующей модели бота. Формула и вероятностный алгоритм бота не заменяются; неподдерживаемая карта получает объяснение. Для скрытых камней с `warningMode: selected` эталон и Мастер проверяются при всех пяти предупреждениях 0,4–1,2 с; в `authored` действуют индивидуальные таймеры карты. Для карты без скрытых камней достаточно одной конфигурации.

На профиль поиск ограничен 180 000 расширениями и 8 секундами, beam 128; весь этап поиска и проверки — 20 секундами и отдельным пределом 100 000 шагов proof. Один забег ограничен 120 секундами. Бюджеты проверяются между атомарными действиями Core. «Не найден» означает неуспех ограниченного поиска или проверки, а не доказанную непроходимость. Условия Мастера используют успешные выбранные IDs и общий счётчик завершённых эффектов; отдельный учёт обслуживания эффекта по каждому ID не реализован. Точный эталон проверяется по полным эффектам и фактической B.

## Черновик только в этом браузере

Через 500 мс после правки и при `pagehide` мастерская сохраняет один версионированный черновик в `localStorage`: точный текст JSON, включая ошибочный или пустой, точный текст нажатий, имя файла, профиль, ось и выбранное предупреждение. Ограничения: 2 МиБ UTF-8 JSON и 128 КиБ нажатий. Визуальная история, найденный результат и серверные файлы в черновик не входят.

При следующем открытии предлагается **восстановить** либо **удалить** сохранённый черновик. До решения он не заменяется встроенной картой или текущими правками. Восстановленный текст проверяется заново; история визуальных действий очищается. Изменение сохранения другой вкладкой приостанавливает автосохранение до решения автора. Черновик привязан к origin и профилю браузера; он не переносится на другой компьютер и не является серверной библиотекой/аккаунтом. Очистка данных браузера удаляет его.

Недоступное хранилище, квота или повреждённое сохранение показываются отдельным статусом и не блокируют редактирование. Пока автосохранение недоступно, используйте «Скачать исходный текст»; для сохранения подготовленного результата всегда нужна его отдельная кнопка скачивания.

Контракт: [API.md](API.md). Правила сохранения: [GATE, HIDDEN, REWARD, FINISH, CONTROL, SOLO, BOT, TRACKFILE](../../../flip-race/docs/flip-race-gameplay-contracts.md). Художественное руководство: [art direction](../../../flip-race/docs/flip-race-art-direction.md).

Проверка исходников из Unity-проекта: `dotnet run --project Tools/TrackWorkshop/Tests/TrackWorkshop.Tests.csproj`. Она проверяет 16 встроенных эталонов по замороженным временам принятой базы, реальные формы, посадочные интервалы и ошибки. Подготовка и граница API: `dotnet run --project Tools/TrackWorkshop/PreparationTests/TrackWorkshop.PreparationTests.csproj`; Web-модели: `node --test Tools/TrackWorkshop/Web/tests`. Это команды проверки, а не утверждение приёмки конкретного пакета.

Сборка: `dotnet build Tools/TrackWorkshop/TrackWorkshop.csproj`. Публикация локальной net8-версии без отдельного runtime pack: `dotnet publish Tools/TrackWorkshop/TrackWorkshop.csproj -c Release --self-contained false -p:UseAppHost=false -o <папка>`; Web и девять JSON каталога копируются в пакет, соседний checkout не нужен. Пакет запускается через `dotnet TrackWorkshop.dll` или `Start.cmd`. Серверная net10-публикация описана в [Deploy/README.md](Deploy/README.md).
