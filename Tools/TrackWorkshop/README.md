# Мастерская трасс 0.1

Локальный отдельный инструмент для JSON-трасс Flip Race Unity 5.4.3, schemaVersion 1 / physicsVersion 1. Игра и её сборка не изменяются. Нужен установленный .NET 8 (для исходников — SDK, для готового пакета — ASP.NET Core Runtime 8 либо SDK 8). Другие зависимости не требуются.

Запустите `Start.cmd` или `Start.ps1` и откройте [мастерскую](http://127.0.0.1:4186/). Окно сервера оставьте открытым; Ctrl+C его останавливает. Запуск работает из любой текущей папки. Порт 4186 должен быть свободен. Сервер слушает только 127.0.0.1; на внешний сервер данные не отправляются. Инструмент не записывает JSON на сервере: открытие и сохранение выполняет браузер.

Выберите встроенную трассу либо откройте свой JSON, отредактируйте текст и обновите схему. Схема использует физические полосы обеих частей ворот, формы финишных стрелок и реальное окно посадочной метки. Это техническое представление координат, а не художественная версия игры. X направлен вправо, Y вниз; коридор 240, радиус героя 14.

Для траектории выберите Основное (Chosen) или Быстрый переворот (FastFlip), длительность предупреждения и список нажатий. Явно выберите единицы: координаты X центра героя или секунды после конца отсчёта. Данные эталона встроенной трассы можно использовать как готовый пример. Вычисление выполняется настоящими production Press/Advance в одном SOLO с камерой, следующей за героем; выбывания за экраном нет. Это не полная симуляция гонки нескольких игроков: их тела и будущие нажатия могут менять безопасное раскрытие скрытых камней.

Отчёт различает принятые, проигнорированные и недостигнутые нажатия; показывает удары, награды, скрытые состояния и фактическое время. Линия пути дискретизирована не реже 120 раз/с, точные точки ввода добавляются отдельно. Метки событий наблюдаются на ближайшем шаге (до 1/120 с); их положение не выдаётся за точную точку контакта. Коллизии вычисляет движок аналитически. Предел: 120 секунд и 4096 нажатий; неверный JSON и ограничения профиля сообщаются явно.

После редактирования геометрии прежние botReferences обычно устаревают. Предпросмотр явно сообщает, если проверка эталонов не прошла, и вычисляет копию без них. Исходный текст не меняется. Для импорта изменённой карты в игру сохраните файл без эталонов через явную кнопку экспорта; такой файл повторно проверяется тем же TrackJson, что использует игра. Валидный хеш не доказывает проходимость, а просмотр эталона не подготавливает бота для новой карты. Solver и калибровка бота в 0.1 не входят.

Контракт: [API.md](API.md). Правила сохранения: [GATE, HIDDEN, REWARD, FINISH, CONTROL, SOLO, BOT, TRACKFILE](../../../flip-race/docs/flip-race-gameplay-contracts.md). Художественное руководство: [art direction](../../../flip-race/docs/flip-race-art-direction.md).

Проверка исходников из Unity-проекта: `dotnet run --project Tools/TrackWorkshop/Tests/TrackWorkshop.Tests.csproj`. Она проверяет 15 встроенных эталонов по замороженным временам принятой базы, реальные формы и ошибки. Сборка: `dotnet build Tools/TrackWorkshop/TrackWorkshop.csproj`. Публикация без отдельного runtime pack: `dotnet publish Tools/TrackWorkshop/TrackWorkshop.csproj -c Release --self-contained false -p:UseAppHost=false -o <папка>`; Web и девять JSON каталога копируются в пакет, соседний checkout не нужен. Пакет запускается через `dotnet TrackWorkshop.dll` или `Start.cmd`.
