# Мастерская трасс 0.5

Отдельный инструмент для JSON-трасс Flip Race Unity, schemaVersion 1 / physicsVersion 1. Для импорта подготовленного файла с ботом нужна игра **5.4.4**: она независимо проверяет маршрут и Мастера перед допуском BOT. Мастерская не перезаписывает файлы игры. Для локального пакета нужен установленный .NET 8 (для исходников — SDK, для готового пакета — ASP.NET Core Runtime 8 либо SDK 8). Серверный Docker-пакет содержит ASP.NET 10 LTS и не требует установки .NET на хосте.

Для локальной работы запустите `Start.cmd` или `Start.ps1` и откройте [мастерскую](http://127.0.0.1:4186/). Окно сервера оставьте открытым; Ctrl+C его останавливает. Запуск работает из любой текущей папки. По умолчанию сервер слушает только 127.0.0.1:4186; на внешний сервер данные не отправляются.

Серверный выпуск поставляется отдельным ZIP: в корне находятся Dockerfile, compose.yaml, Caddyfile, .env.example и пошаговый README.md, а в app/ — готовое приложение. Он рассчитан на отдельный домен, HTTPS и вход разработчика по паролю; публикация только содержимого Web/ не выполняет расчёт траекторий. При сетевом использовании JSON и нажатия передаются серверу для проверки и расчёта. Пользовательские файлы не сохраняются на сервере: открыть/скачать их позволяет браузер. Редакторы разных людей независимы; общей библиотеки и совместного редактирования нет.

Выберите встроенную трассу либо откройте свой JSON. Для создания выберите тип в панели добавления и щёлкните на подробной схеме. Для посадочной метки или связанного бонуса сначала выберите нужное препятствие; посадка требует именно камень. Новые объекты получают уникальные ID. Встроенные файлы не перезаписываются.

Щёлкните объект, чтобы выбрать его. Тяните сам объект для перемещения, а появившиеся ручки — для изменения размеров. JSON обновится после отпускания мыши. Пустое место схемы, либо Alt/пробел при перетаскивании, двигает обзор. Камни сохраняют стену; ворота — обе части и смещения; посадка остаётся на поверхности камня. Размер финишных стрелок фиксирован физикой игры, поэтому ручек размера у них нет.

Кнопка удаления или Delete вне текстового поля удаляет выбранный объект. При удалении препятствия удаляются и связанные награды; число объектов показано заранее. Если удалён последний скрытый камень из карты с авторскими таймерами, предупреждения переключаются в обычный режим с уведомлением. «Отменить» и «Повторить» возвращают визуальные действия; Escape отменяет незавершённый жест/добавление. Ручная правка JSON или открытие другого файла сбрасывает визуальную историю, чтобы она не затирала новый текст.

Схема использует физические полосы обеих частей ворот, формы финишных стрелок и реальное окно посадочной метки. Это техническое представление координат, а не художественная версия игры. X направлен вправо, Y вниз; коридор 240, радиус героя 14.

Для траектории выберите Основное (Chosen) или Быстрый переворот (FastFlip), длительность предупреждения и список нажатий. Явно выберите единицы: координаты X центра героя или секунды после конца отсчёта. Данные эталона встроенной трассы можно использовать как готовый пример. Вычисление выполняется настоящими production Press/Advance в одном SOLO с камерой, следующей за героем; выбывания за экраном нет. Это не полная симуляция гонки нескольких игроков: их тела и будущие нажатия могут менять безопасное раскрытие скрытых камней.

Отчёт различает принятые, проигнорированные и недостигнутые нажатия; показывает удары, награды, скрытые состояния и фактическое время. Линия пути дискретизирована не реже 120 раз/с, точные точки ввода добавляются отдельно. Метки событий наблюдаются на ближайшем шаге (до 1/120 с); их положение не выдаётся за точную точку контакта. Коллизии вычисляет движок аналитически. Предел: 120 секунд и 4096 нажатий; неверный JSON и ограничения профиля сообщаются явно.

После редактирования геометрии прежние botReferences обычно устаревают. Предпросмотр явно сообщает, если проверка эталонов не прошла, и вычисляет копию без них. Проверка не переписывает исходный текст. Обычная кнопка скачивания позволяет экспортировать проверенный JSON без устаревших эталонов для человеческих режимов. «Скачать исходный текст» сохраняет точный текущий текст, включая ошибки. Просмотр нажатий старого эталона не создаёт новый; валидный хеш сам по себе не доказывает проходимость.

## Подготовить карту для бота

1. Откройте или отредактируйте JSON и дождитесь проверки. Выберите ниже готовое управление: Основное (`Chosen`) или Быстрый переворот (`FastFlip`). Ограничение `chosen-only` сохраняется. Мастерская готовит текущий выбранный профиль; для второго профиля можно выполнить отдельный запрос через API.
2. Проверьте «ID подготовленной трассы». Для встроенной карты заранее предложен `custom-<исходный-id>` и показано «Будет создан новый ID для импорта». ID можно изменить. Встроенные и исторические ID зарезервированы; повторный импорт уже занятого пользовательского ID игра также отклонит. Сервер не знает каталог другой игровой сессии и не гарантирует глобальную уникальность ID.
3. Нажмите «Подготовить бота». Находится хороший чистый маршрут с совместимыми наградами и полным финишным рывком, затем проверяются эталон и настоящий Мастер. Ручной список X, если он корректен, служит необязательной подсказкой; новый поиск работает и без него. Ввод по времени подсказкой поиска не является. Кнопка «Отменить поиск» прерывает запрос.
4. Результат показывает профиль, выбранные IDs наград, время эталона и статус проверки Мастера; найденный путь показывается обычным проигрывателем. Исходный JSON и ручной список нажатий остаются прежними. Поиск не обещает оптимум или сбор всех альтернатив. Изменение исходного JSON, управления, предупреждения или выходного ID сбрасывает результат.
5. Нажмите отдельную кнопку **«JSON для игры с ботом»**. Этот файл содержит новый ID копии и проверенные `botReferences`; обычное скачивание исходника его не заменяет. В игре 5.4.4 откройте «Выбрать трассу» → «Импорт JSON» и выберите файл, затем подготовленное управление. Карта сразу доступна людям; BOT включается только после независимой проверки выбранного профиля в игре. Импорт и допуск живут до перезагрузки игровой страницы.

Нужны хотя бы одно логическое препятствие (`C > 0`), ровно одна финишная цель с полным эффектом и допустимое соотношение пользы/стоимости `B/C` существующей модели бота. Формула и вероятностный алгоритм бота не заменяются; неподдерживаемая карта получает объяснение. Для скрытых камней с `warningMode: selected` эталон и Мастер проверяются при всех пяти предупреждениях 0,4–1,2 с; в `authored` действуют индивидуальные таймеры карты. Для карты без скрытых камней достаточно одной конфигурации.

На профиль поиск ограничен 180 000 расширениями и 8 секундами, beam 128; весь этап поиска и проверки — 20 секундами и отдельным пределом 100 000 шагов proof. Один забег ограничен 120 секундами. Бюджеты проверяются между атомарными действиями Core. «Не найден» означает неуспех ограниченного поиска или проверки, а не доказанную непроходимость. Условия Мастера используют успешные выбранные IDs и общий счётчик завершённых эффектов; отдельный учёт обслуживания эффекта по каждому ID не реализован. Точный эталон проверяется по полным эффектам и фактической B.

## Черновик только в этом браузере

Через 500 мс после правки и при `pagehide` мастерская сохраняет один версионированный черновик в `localStorage`: точный текст JSON, включая ошибочный или пустой, точный текст нажатий, имя файла, профиль, ось и выбранное предупреждение. Ограничения: 2 МиБ UTF-8 JSON и 128 КиБ нажатий. Визуальная история, найденный результат и серверные файлы в черновик не входят.

При следующем открытии предлагается **восстановить** либо **удалить** сохранённый черновик. До решения он не заменяется встроенной картой или текущими правками. Восстановленный текст проверяется заново; история визуальных действий очищается. Изменение сохранения другой вкладкой приостанавливает автосохранение до решения автора. Черновик привязан к origin и профилю браузера; он не переносится на другой компьютер и не является серверной библиотекой/аккаунтом. Очистка данных браузера удаляет его.

Недоступное хранилище, квота или повреждённое сохранение показываются отдельным статусом и не блокируют редактирование. Пока автосохранение недоступно, используйте «Скачать исходный текст»; для сохранения подготовленного результата всегда нужна его отдельная кнопка скачивания.

Контракт: [API.md](API.md). Правила сохранения: [GATE, HIDDEN, REWARD, FINISH, CONTROL, SOLO, BOT, TRACKFILE](../../../flip-race/docs/flip-race-gameplay-contracts.md). Художественное руководство: [art direction](../../../flip-race/docs/flip-race-art-direction.md).

Проверка исходников из Unity-проекта: `dotnet run --project Tools/TrackWorkshop/Tests/TrackWorkshop.Tests.csproj`. Она проверяет 15 встроенных эталонов по замороженным временам принятой базы, реальные формы и ошибки. Подготовка и граница API: `dotnet run --project Tools/TrackWorkshop/PreparationTests/TrackWorkshop.PreparationTests.csproj`; Web-модели: `node --test Tools/TrackWorkshop/Web/tests`. Это команды проверки, а не утверждение приёмки конкретного пакета.

Сборка: `dotnet build Tools/TrackWorkshop/TrackWorkshop.csproj`. Публикация локальной net8-версии без отдельного runtime pack: `dotnet publish Tools/TrackWorkshop/TrackWorkshop.csproj -c Release --self-contained false -p:UseAppHost=false -o <папка>`; Web и девять JSON каталога копируются в пакет, соседний checkout не нужен. Пакет запускается через `dotnet TrackWorkshop.dll` или `Start.cmd`. Серверная net10-публикация описана в [Deploy/README.md](Deploy/README.md).
