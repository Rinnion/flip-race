# Проверка Компании с ботами

Запуск из корня Unity-проекта с .NET 8.

```powershell
dotnet run -c Release --project Tools/PartyBotsRegression -- Assets/StreamingAssets/Tracks Assets/Scripts/Core v57-regression-local.json
dotnet run -c Release --project Tools/UnifiedRaceRegression -- Assets/StreamingAssets/Tracks v57-legacy-local.json Verification/v56-regression-baseline.json
dotnet run -c Release --project Tools/ParityRunner -- Tools/engine-parity-fixtures.tsv.gz
```

- Перебираются все 28 распределений людей и ботов по двум, трём и четырём местам. Проверяются назначение сложности, разные семена, выбор героя, готовность, старт без людей, отказ на ввод в место бота и прежняя физика полностью человеческой Компании.
- Три тестовых источника воспроизводят фиксированные команды на одной шкале. Независимый мир повторяет каждый шаг и ввод через обычную физику. Проверяются порядок места при одинаковом времени, кратчайший шаг, пауза, неверная привязка и отказ при попытке добавить второй комплект источников к живой Компании.
- Три полных прогона используют автоматические живые источники. Отдельный мир повторяет наблюдаемые команды и временные границы. Обычная проверка таймлайна допускает 0,000002 для чисел из-за восстановления интервала из часов. Проверяются физическое состояние, награды, терминальные исходы, продолжение гонки после последнего человека или бота, ручной повтор и новая последовательность для каждого места.
- На скрытой трассе сравнивается состояние всех четырёх тел и общий таймер. Копия мира и прогноз не получают автоматические источники живой Компании. Локальная карта допускает ботов после штатной проверки подготовленного эталона, затем использует общее ускорение. Изменение геометрии отменяет допуск.

Отчёт хранит хеши проверенных файлов Core и измерения `RaceRunner.Advance` в .NET. Обращение к прогнозу входит в это время. Независимое воспроизведение и сравнение вынесены за измеряемый вызов. Измерение четырёх ботов выполняется после остальных сценариев в том же процессе. Состав, параметры и seed записаны вместе с результатом. Такой замер не заменяет проверку времени кадров WebGL.

Для сверки прежнего режима используются те же 23 сценария инструмента `UnifiedRaceRegression`. Для выборки с разгоном из прогона `--surface` сравниваются хеши Mixed/Основной со стандартными настройками и Intercepts с обоими профилями и контрастными настройками. Исходники версии 5.6.0 доступны в `ef41e21`, прежние фикстуры не меняются. [Результаты поставки](../../Verification/v57-regression-party-bots.json).
