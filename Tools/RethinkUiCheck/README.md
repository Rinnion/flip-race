# Rethink menu checks

Run `pwsh -NoProfile -File Tools/RethinkUiCheck/Run.ps1` from the Unity project root after freezing Core, Presentation, Web and authored track JSON. `-BuildOnly` prepares and compiles the check. The script reuses HiddenUiCheck's native environment transforms and checks production Pointer, Update, menu layout and Apply against the installed JSON catalogue. It checks source and data hashes again at the end of the run.

At 568×320 and 1280×720 with DPR 1, 2 and 3, the check exercises eight disjoint track targets, both presets in SOLO, human parties of 2–4 and the previous standalone bot, and exact equivalent custom settings in SOLO. Modified custom settings leave the map and active race intact and the menu names both supported presets. Fast also applies with the preliminary standalone bot and with two bots in a four-seat party for both algorithms. The test checks ready state, all six authored 0.35-second warnings and all five global warning choices across map switches. `Tools/NewTrackBotUiCheck` exercises the full previous-bot map, profile, difficulty and delay matrix in the offline C# catalogue.

The previous seven-map scenarios remain in HiddenUiCheck. Managed checks do not prove visual fade, font fit, native browser events, playability or physical-phone usability. Actual build rendering must check both renderers, floor/ceiling, safe activation postponement and pause, following [art direction](../../../flip-race/docs/flip-race-art-direction.md).
