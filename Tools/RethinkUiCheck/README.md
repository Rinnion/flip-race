# Rethink menu checks

Run `pwsh -NoProfile -File Tools/RethinkUiCheck/Run.ps1` from the Unity project root after freezing Core/Presentation/Web. `-BuildOnly` prepares and compiles without asserting a final result. The script reuses HiddenUiCheck's exact native environment transforms; production Pointer, Update, menu layout and Apply methods remain intact. A final result is rejected if a production source hash changes during execution.

Coverage: eight whole disjoint track targets at 568×320/1280×720 and DPR1/2/3; selected rethink remains unchanged when Fast or modified custom cannot Apply; explicit Chosen and equivalent Chosen custom apply; SOLO and human parties2–4; BOT rejection without Game replacement or seed consumption; explicit old-map BOT choice; authored timing row cannot open global settings, and all five global warning choices survive moving between ordinary hidden maps and rethink.

The previous seven-map scenarios remain in HiddenUiCheck. Managed checks do not prove visual fade, font fit, native browser events, playability or physical-phone usability. Actual build rendering must check both renderers, floor/ceiling, safe activation postponement and pause, following [art direction](../../../flip-race/docs/flip-race-art-direction.md).
