# JSON tracks UI checks

Run `pwsh -NoProfile -File Tools/JsonTracksUiCheck/Run.ps1` from the Unity project root after coordinating a production source/data freeze. `-BuildOnly` compiles without running the matrix. The final runner records and verifies hashes of Core/Presentation/Web, authored track JSON, the HTML/import bridge and package manifests.

Managed coverage uses production Pointer, Update, menu and raw-file import callbacks. It checks no playable Game before fetch or after load failure, the existing eight card positions, ninth-cell import, additional pages with 44-unit controls, session import and explicit notice, malformed/duplicate/read-error recovery without replacing Game or catalogue, metadata-driven chosen-only and authored-warning restrictions, imported SOLO/retry/party, imported BOT rejection without seed changes, all 15 builtin BOT pairs and retained C# practices. Native environment aliases are the established HiddenUiCheck seams; only native bridge publication is disabled with FLIP_MANAGED_CHECK.

The JavaScript check executes the actual HTML template script with a bounded DOM/file-reader environment. It checks boot gating, visible literal errors, retry, import positioning, synchronous file chooser activation, raw text forwarding, pre-read 2 MiB cap, cancellation, read failure and the unchanged count of three diagnostic observers. It does not establish actual URL fetch, native chooser behavior, rendering or physical-phone usability; root verifies those in the WebGL build. Synthetic terminal fixtures only establish Retry routing and retained settings.
