# Проверка разгона от бега

Из корня Unity-проекта: `dotnet run --project Tools/SurfaceRunCheck/SurfaceRunCheck.csproj`.

Проверка использует настоящую Core-симуляцию. Десять сценариев: аналитический путь и скорость, расход до нуля, посадка и воздушный повтор, пауза/отсчёт/восстановление/повтор/snapshot, сложение обычных и финишных эффектов, непрерывные контакты ворот и колец, отмеченная посадка и сход с камня, штрихи финишной цели и точное время, скрытый мир, выбывание у постоянной камеры, nonshared finish/grace и запрет включения для BOT. Крупные и мелкие шаги проверяют отсутствие пропущенных событий.

Регрессия всех прежних механик при OFF: `dotnet run --project Tools/ParityRunner/ParityRunner.csproj -- Tools/engine-parity-fixtures.tsv.gz`. Фикстуры не регенерировать ради прохождения проверки. Эта проверка не подтверждает изображение, удобство управления или физический телефон. Интерфейс — `Tools/SurfaceRunUiCheck/Run.ps1`, затем настоящий WebGL в браузере.

Принятые параметры и ограничения: [статья продукта](../../../flip-race/docs/features/surface-acceleration.md). Приёмка выпуска: [STATUS](../../Verification/V55-SURFACE-RUN-STATUS.md).
