# Проверка разгона от бега

Из корня Unity-проекта: `dotnet run --project Tools/SurfaceRunCheck/SurfaceRunCheck.csproj`.

Проверка использует настоящую Core-симуляцию. Матрица из 30 сочетаний (пять темпов, две кривые, три предела) сверяет запас и путь с аналитическими формулами на крупных и мелких шагах. Она проверяет снижение запаса в воздухе, приземление и последующий разгон на потолке.

Отдельные сценарии проверяют паузу, отсчёт, восстановление, повтор и копию попытки, сложение обычных и финишных бонусов, контакты смещённых ворот и колец, отмеченную посадку и сход с камня, штрихи финишной цели и точное время финиша. Для экспоненциального разгона проверяются касание кольца и промах рядом, момент раскрытия скрытого камня, выбывание у постоянной камеры и случай, когда герой успевает сравняться со скроллом. Для гонки без общей камеры проверяется срок завершения после первого финиша. Проверки настроек охватывают недопустимые значения и запрет разгона в BOT.

Регрессия всех прежних механик при OFF: `dotnet run --project Tools/ParityRunner/ParityRunner.csproj -- Tools/engine-parity-fixtures.tsv.gz`. Фикстуры не регенерировать ради прохождения проверки. Эта проверка не подтверждает изображение, удобство управления или физический телефон. Интерфейс — `Tools/SurfaceRunUiCheck/Run.ps1`, затем настоящий WebGL в браузере.

Принятые параметры и ограничения описаны в [статье продукта](../../../flip-race/docs/features/surface-acceleration.md). Результаты выпуска указаны в [STATUS 5.5.1](../../Verification/V551-SURFACE-SETTINGS-STATUS.md).
