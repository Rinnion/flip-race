# Проверка расширенного набора катикаавров

Из корня Unity-проекта: `./Tools/RosterArtworkCheck/Run.ps1`.

Скрипт извлекает исходники старых шести героев из фиксированной ревизии `ef4873c`, компилирует их отдельно и сравнивает RGBA с текущими кадрами. Новые четыре героя проверяются во всех группах поз и четырёх местах. Результат, исходные хеши и листы поз сохраняются в `Verification/v584-art/`.

[Методика и ограничения](../../Verification/v584-art/pose-checks.md). Настольный заменитель Unity позволяет проверить пиксели и кэш; он не устанавливает задержку выбора на телефоне и не заменяет WebGL-приёмку. Сценарий закреплён за набором 5.8.4; изменение старых образов потребует отдельного решения об эталоне.
