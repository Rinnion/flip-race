# Независимая проверка предварительного бота

Из корня Unity-проекта с .NET 8:

```powershell
dotnet run -c Release --project Tools/PrestartBotsRegression -- Assets/StreamingAssets/Tracks Verification/v58-review-runtime.json
```

Проверка заново строит полные ленты на двух встроенных трассах и на новой импортированной геометрии без эталона. На второй версии новой трассы с тем же ID перемещён один камень. Ленты воспроизводятся обычными нажатиями и шагами мира с другой длительностью кадров. Отдельные сценарии проверяют ключ и загрузку кэша, фактический повтор, отказ при испорченной ленте и при изменении карты после установки плана.

На скрытой трассе проверяются четыре бота и один человек с тремя ботами, один ход времени мира, отдельный явный старт и повтор с новым seed. Проверка с намеренно невозможной границей камеры требует отказа, если в общем заезде выбыли все боты. [Результат](../../Verification/v58-review-runtime.json) хранит хеши исходников, длительности и суммарные выделения памяти в Release .NET. Время подготовки включает вычисления и повторы без ожидания кадров интерфейса. Выделения памяти измерены за всю работу и не показывают пиковое потребление или удержанную память WebGL.

Старый бот и другие режимы проверены отдельными существующими инструментами. [Результат регрессии](../../Verification/v58-review-preservation.json).
