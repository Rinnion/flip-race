# Проверка предварительного бота

Запуск из корня Unity-проекта с .NET 8.

```powershell
dotnet run -c Release --project Tools/PrestartBotsCheck
```

Необязательный аргумент после `--` задаёт путь JSON-отчёта. Отчёт содержит хеши проверенных исходников, идентификаторы конфигураций и фактически собранные награды и удары. `--artifacts-path` задаёт отдельный каталог для сборки, если каталоги проекта доступны только для чтения.

Проверка выполняет поиск и воспроизведение на «Длинных сериях», «Полосе уловок» и «Проявлении» без авторских эталонов с обоими готовыми профилями управления. Дополнительно проверяются новый локальный импорт без эталона, два последовательных заезда четырёх ботов со скрытыми блоками, смена seed, ввод человека и ограниченное восстановление при фактическом отклонении в обеих камерах. Проверка отклоняет кэш с физически недопустимой последовательностью и запуск состава из одних ботов, если совместный прогноз не довёл до финиша ни одного участника.

Замер подготовки выполняет порции `Step(192)` подряд. Он фиксирует время, число проверенных состояний и шагов повтора, наибольшую длительность порции и её управляемые выделения в .NET. Время между кадрами браузера в эти значения не входит. Приёмка скорости WebGL и сохранения на устройстве проводится отдельно.
