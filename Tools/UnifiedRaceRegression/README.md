# Проверка общего цикла гонки

Запуск из корня Unity-проекта с .NET 8. Вторая команда использует исторические фикстуры без перезаписи.

```powershell
dotnet run -c Release --project Tools/UnifiedRaceRegression -- Assets/StreamingAssets/Tracks v56-regression-current.json Verification/v56-regression-baseline.json
dotnet run -c Release --project Tools/ParityRunner -- Tools/engine-parity-fixtures.tsv.gz
```

Проверка загружает поставляемые JSON-файлы трасс. Сценарии охватывают Мастера на 15 парах трасса/профиль из эталона 5.6, четыре остальных уровня бота с фиксированными seed и вводом человека, а также четыре человеческих гонки в режимах SOLO, Компания и сплит. В двух человеческих гонках включён разгон. Для бота он выключен на всём наборе. Ввод подаётся до шага кадра, как в игровом `Update`. Новая пара «Передумай» / «Быстрый переворот» проверяется отдельно. [Проверка новой пары](../NewBotReferenceCheck/README.md).

В каждом сценарии отдельный мир получает те же фактические команды и шаги через `RaceSimulation.Press` и `RaceSimulation.Advance`. Сравнение после каждого шага, команды и паузы проверяет точное равенство сериализованного состояния. В хеш трассы входят длительность шага, результат ввода, положения, вертикальная скорость, запас разгона, эффекты, награды, скрытые блоки, камера, финиши и победитель. Хеш решений охватывает намерения, RNG, выбранные действия, исходы и счётчики поиска. Время работы планировщика не входит в хеш. Полный отчёт содержит фактические попытки ввода.

Для повторного получения исходной трассы извлеките `Assets/Scripts/Core` и `Assets/StreamingAssets/Tracks` из коммита `3ec4965` в отдельный каталог и передайте этот абсолютный путь в `-p:BaselineRoot=...`. Передайте абсолютный путь к сохранённому каталогу трасс первым аргументом и имя нового отчёта вторым. Параметр `BaselineRoot` компилирует старые точки входа вместо общего исполнителя.

В исходной и перенесённой реализации совпали полные отчёты по 23 сценариям, включая 109 713 шагов и 554 принятые команды бота. Зафиксировано 560 принятых и 387 отклонённых человеческих команд, 23 паузы и 0 подавленных ботом команд. Все 15 заездов Мастера завершились без ударов у бота. Проверка выполняется в .NET и не измеряет кадры WebGL или доставку сенсорных событий. [Базовые хеши и счётчики](../../Verification/v56-regression-baseline.json).

## Разгон в режиме BOT

```powershell
dotnet run -c Release --project Tools/UnifiedRaceRegression -- Assets/StreamingAssets/Tracks v56-regression-surface.json --surface
dotnet run -c Release --project Tools/PreparedTracksCheck
```

600 случаев проверяют все 300 наборов для двух профилей. Два участника BOT и два участника Компании получают одинаковые команды на реальной трассе. Сравниваются полные состояния игроков после команд и шагов, включая накопление на опоре, полёт, удар и выбранный сброс или сохранение запаса.

В 16 полных гонках с включённым разгоном планировщик выдаёт реальные команды, которые воспроизводятся через обычную физику в отдельном мире. Выборка включает два профиля, стандартный набор и крайние настройки, обычную и скрытую трассы, ввод человека и два заезда на локальном импорте. Отдельные случаи проверяют, что прогноз копирует реальный запас, настройки и раскрытие скрытых блоков. Для локального импорта исходный маршрут и Мастер проходят обычную проверку без разгона. После допуска живой заезд и прогноз используют выбранный разгон, а изменение геометрии отменяет допуск. `PreparedTracksCheck` проверяет также повреждённый маршрут, поддельный эталон и разные предупреждения.

Равенство физики и сохранение формулы намерений не задают Мастеру обязательный чистый маршрут при любом разгоне. В отчёте сохраняются реальные удары и финиши каждого прогона. [Результаты проверок](../../Verification/v56-regression-surface.json).
