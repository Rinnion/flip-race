# Проверка составов компании с ботами

Запуск из корня Unity-проекта на .NET 8.

```powershell
dotnet run -c Release --project Tools/PartyBotsCheck
```

Необязательный аргумент после `--` задаёт путь JSON-отчёта с исходами и SHA256 проверенных исходников. Если каталог проекта доступен только для чтения, `--artifacts-path` позволяет указать отдельное место для сборки.

Проверка перебирает все 28 составов на 2–4 места, включая компании без людей, и проводит пять полных гонок с 0–4 ботами. Она охватывает оба готовых профиля и обе камеры, разгон и скрытые блоки, продолжение после выбывания последнего человека и завершение каждого участника. Отдельно проверяются готовность, принадлежность ввода, физические снимки, явные старт и повтор, сохранение героев и настроек, отдельная случайная последовательность и сброс планировщиков на повторе. Допуск сверяется для ручного управления, ограниченной карты и импорта до и после проверки маршрута и изменения геометрии.

Проверка прогнозных буферов сверяет состояние после отката и начала нового кандидата с публичным снимком. Она проверяет личные наборы, общие скрытые блоки, очереди эффектов, поля полёта и разгона, а также сохранение общих ссылок внутри снимка и отсутствие таких ссылок между снимками.

Для регрессии по памяти на «Проявлении» с четырьмя ботами и включённым разгоном используется тот же `RaceRunner.Advance`, что и в Unity.

```powershell
dotnet run -c Release --project Tools/PartyBotsCheck -- --allocation
```

Проверка измеряет управляемые выделения за один вызов `Advance`. По умолчанию шаг равен 0,3 с, верхней границе игрового кадра перед автоматической паузой. Для этой фиксированной гонки проверяется порог 32 МиБ на кадр. Необязательные параметры после `--allocation` задают шаг, число ботов, ID трассы, включение разгона и seed. Измерение .NET служит регрессией для сценария, а объём памяти и стабильность WebGL проверяются в браузере.

Проверка выполняет общий Core. Приёмка браузерного интерфейса и WebGL-сборки проводится отдельно.
