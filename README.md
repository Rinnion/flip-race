## Управление и правила v3

- Перед готовностью каждый выбирает Листика, Капельку, Травника или Цветка. Характеристики одинаковые; одинаковых героев различают шарфы и цвет интерфейса.
- В верхней панели выбирают общий ритм и включают либо выключают отрицательные кольца. Флаг применяется вместе с выбранной трассой; закрытие окна отменяет черновой выбор. Остальные камни, положительные кольца и длина не меняются.
- Оба подтверждают готовность на своих половинах, затем идёт отсчёт 3–2–1. `A` управляет верхней половиной, `L` — нижней; доступны мышь и касания.
- Отдельное нажатие меняет пол на потолок или обратно. Перелёт длится **0,8 с**. Нажатия во время перелёта/восстановления не ставятся в очередь; удержание не повторяет действие.
- Круг с плюсом может требовать позднего ухода **до камня** или своевременного возврата **после камня**. Награда подтверждается чистым завершением манёвра. Слишком ранний возврат может задеть задний край; поздний пропускает кольцо. Безопасный отказ от кольца не штрафуется.
- Положительное кольцо повышает скорость с 220 до 330 единиц/с на 0,6 с движения: полный выигрыш **0,3 с**. Ромб с минусом снижает её до 110 на 0,6 с: потеря **0,3 с**, без блокировки переворотов.
- Эффекты выполняются последовательно по FIFO. Новое кольцо сохраняет остаток действующего эффекта и добавляет полный следующий. Полная пара «плюс/минус» взаимно компенсирует время; кольца независимы для игроков.
- Столкновение останавливает продвижение и перелёт на **0,5 с**, замораживает эффект и отменяет неподтверждённую награду текущего манёвра. Ранее заработанные сохраняются.
- После первого финиша отстающему даётся до 3,5 с. Возможна точная ничья. Реванш сохраняет героев, ритм и отрицательные кольца, очищает забег и требует готовности обоих. После результата можно выбрать другой ритм.
- Пауза — кнопкой или `Esc`, продолжение — явным действием. Обработчики потери фокуса, скрытия страницы, portrait до 700 CSS-пикселей шириной и разрыва кадров >0,3 с приостанавливают активный забег. Границы фактической проверки перечислены в отчёте.
- Нижняя кнопка открывает отдельную шестишаговую пробу серии и возвращает выбранную гонку. Звук и fullscreen необязательны.

| Маршрут без столкновений | Полная гонка |
|---|---:|
| Без эффектов | 36,0 с |
| Все 6 положительных, отрицательные обойдены | 34,2 с |
| Все 6 положительных и оба отрицательных | 34,8 с |

Два положительных и одно столкновение дают −0,1 с относительно безопасного времени. В искусственном тесте с эффектом у финиша учитывается только реально отработанная часть; подготовленные маршруты завершают все эффекты до финиша.

## Три ритма

| Трасса | Структура | Действия | Максимальный интервал между действиями |
|---|---|---:|---:|
| Длинные серии (`v3-long`) | Три группы по шесть | 18 | 2,554545 с |
| Короткие связки (`v3-short`) | Шесть групп по три | 18 | 3,090909 с |
| Ровный поток (`v3-flow`) | Почти равномерная последовательность | 18 | 1,863636 с |

Интервалы измерены по фактическому времени идеального маршрута с ускорениями. Первый ввод у всех на 1,781818 с; от последнего ввода до финиша — соответственно 2,681818 / 1,854545 / 2,536364 с. Удаление любого одного из 18 действий ухудшает результат. Это автоматические показатели маршрутов, а не оценка удобства двумя игроками.

Короткая проба (`v3-series`): шесть действий, два положительных и одно отключаемое отрицательное. Безопасное время — 12,7272727… с, идеальное — 12,1272727… с, с намеренным отрицательным — 12,4272727… с. Прототип проверен моделью и реальными браузерными нажатиями **до** создания полных трасс.

Сохранены компактная структура JS, CSS-пиксели, четыре героя и native C#-рисование. Для двух выбранных героев кэшируются 384 кадра и 8 превью 128×128 RGBA32 без mipmap — 24,5 MiB данных текстур. Генерация повторно использует рабочие буферы. Это расчёт текстур, не измерение полной памяти вкладки/GPU. Inter Regular и SemiBold распространяются с SIL OFL 1.1.
## Открытие и сборка

Редактор — **Unity 6000.0.64f1** с WebGL Build Support. В Unity Hub выберите **Add → Add project from disk** и `F:/Home/Game/flip-race-unity`. После импорта откройте `Assets/Scenes/FlipRace.unity` и нажмите Play. Web-сборка — **Flip Race → Build WebGL**.

```powershell
Set-Location F:/Home/Game/flip-race-unity
$unityBuild = Start-Process -FilePath 'F:/Program Files/Unity/Hub/Editor/6000.0.64f1/Editor/Unity.exe' -ArgumentList @('-batchmode', '-nographics', '-quit', '-projectPath', 'F:/Home/Game/flip-race-unity', '-buildTarget', 'WebGL', '-executeMethod', 'FlipRace.Editor.BuildGame.WebGL', '-logFile', 'F:/Home/Game/flip-race-unity/Logs/build-webgl.log') -WindowStyle Hidden -Wait -PassThru
if ($unityBuild.ExitCode -ne 0) { throw 'Unity build failed; inspect Logs/build-webgl.log' }
```

Перед пакетной сборкой закройте проект в редакторе. Лицензия установленного редактора подтверждена успешными сборками; на другом компьютере настройте её через Unity Hub. Результат — `Builds/WebGL/`. После изменения C#, ресурсов или Web-шаблона пересоберите Web и ZIP.

`Assets/Editor/BuildGame.cs` фиксирует IL2CPP, WebGL 2, gzip и `decompressionFallback=true`. Файлы `.unityweb` распаковываются загрузчиком без нативного HTTP `Content-Encoding`. Heap: начальные 64 MiB, максимум 256 MiB; это не общая память вкладки. `stripEngineCode=false` сохранён после исправления ошибки `class ID 115` у IMGUI skin; managed stripping — Low. GUI доступен и в обычном редакторе.

## Локальный запуск и ZIP

Нужен Node.js 20 или новее, npm-зависимости не требуются.

```powershell
Set-Location F:/Home/Game/flip-race-unity
node Tools/serve.mjs
```

Откройте <http://localhost:4180/>. Телефону в той же сети нужен адрес `Phone on the same Wi-Fi` из вывода сервера. Выберите нужный адаптер; доступ зависит от сети и брандмауэра. Остановка — Ctrl+C. Другую папку можно передать первым аргументом; `PORT` и `HOST` меняют значения `4180` и `0.0.0.0`.

`file://` не подходит. Сервер выставляет MIME для `.wasm`, `.data` и `.js`, поддерживает `.gz`/`.br` с `Content-Encoding`; `.unityweb` отдаёт без HTTP-распаковки. Кэш отключён. Настройки сборки и заголовки должны совпадать. [Unity: размещение Web-сборки](https://docs.unity3d.com/6000.0/Documentation/Manual/webgl-deploying.html).

```powershell
node Tools/verify-build.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File Tools/package.ps1 -Output Releases/flip-race-v3-webgl.zip
```

Путь v3 — `Releases/flip-race-v3-webgl.zip`, manifest создаётся рядом. В корне ZIP находится `index.html`; внутри только Web-файлы. Проверяются относительные ссылки HTML/CSS и Unity runtime, точный регистр, согласованное сжатие, заголовок WebAssembly и ограничения размера/числа файлов. Затем ZIP перечитывается и сверяется SHA-256 каждой записи. Другую папку сборки задаёт параметр `-BuildDirectory F:/path/to/WebGL`.

Финальный [ZIP v3, сборка 3.0.1](Releases/flip-race-v3-webgl.zip): **8 503 651 байт / 8,110 MiB**. Web-сборка: **8 632 825 байт / 8,233 MiB**, 5 файлов. SHA-256 ZIP: `ff069f10a222138cdf4eb57615b6c2acc45e3c8e210e07f6a223ac1961a5b489`. [Manifest](Releases/flip-race-v3-webgl.zip.manifest.json) подтверждает `index.html` в корне и SHA-256 всех записей. Архивы `flip-race-v2-webgl.zip` и `flip-race-unity-webgl.zip` относятся к истории v2 и v1.

Для ручной загрузки на itch.io создайте **HTML Game**, загрузите ZIP и отметьте файл как игру в браузере. Используйте адаптивную область, например 960×540, и Click to Play. Mobile Friendly включайте после проверки на целевых телефонах; ориентация — горизонтальная. Fullscreen необязателен. Проверьте черновой предпросмотр до публикации. Загрузка и публикация в этой задаче не выполняются. [itch.io: HTML5, ZIP и mobile](https://itch.io/docs/creators/html5).

Все runtime-пути относительные и учитывают регистр. `Assets`, `Library`, исходники, логи и отчёты в HTML-архив не включаются.
