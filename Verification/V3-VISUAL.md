# V3.0.1: компактное оформление и движение

**Готово: сборка, браузерные сценарии, финальная консоль и ZIP проверены.** Дата: 15 октября 2026 года.

## Референс и изменения

Референс — исходная JS-игра: [styles.css](../../flip-race/styles.css), [index.html](../../flip-race/index.html), [src/app.js](../../flip-race/src/app.js), [src/renderer.js](../../flip-race/src/renderer.js). Соседний JS-проект не изменялся.

Размер арены сохранён. Правка уменьшает дополнительные окна и плотность текста, сохраняя четыре героя и правила v3.

| Элемент | Финальное изменение |
|---|---|
| Выбор ритма | Максимум **350×232 CSS px** вместо 470×310; строки по 34 px, краткие названия и переключатель отрицательных |
| Правила | **410×282 px**, короткие пункты и кнопка 142×31 |
| Выбор героев | Зоны 74×34 desktop / 62×30 compact; четыре фоновые карточки убраны, выделен только выбранный герой |
| Готовность | Возвращены «Переверни гонку.» / «Всё, я готов!»; кнопка 164×32 desktop / 140×26 compact. При lane <135 px выбор поднят ещё на 5 px |
| Во время гонки | Длинные предупреждения о каждом кольце убраны; подробные объяснения оставлены в тренировке |
| Скругления | Исправлено многократное наложение полупрозрачной заливки и видимые полосы |
| Широкий compact | Как в JS, занимает всю ширину без ограничения 1320 px |
| Движение | Более заметные лапы, шарф, наклон и подскок; бег привязан к фактической дистанции, поза перелёта — к его прогрессу |

Все размеры ограничены viewport. Сохранены палитра JS, верхняя панель, две противоположные половины, прогресс и нижняя кнопка.

## Память и проверка исходников

Первый кандидат 3.0.1 скомпилировался, но получил **out of memory при запуске WebGL**: [ранний журнал ошибок](v3-visual-first-build-errors.json). Для генерации кадров теперь повторно используются рабочие буферы и массив загрузки текстуры. Финальная сборка запускается; повторные переключения героев 2/3 и выбор одинакового героя 3 обоими прошли. Heap остался **64 MiB начально / 256 MiB максимум**.

Кэш двух выбранных героев — 384 кадра и 8 превью 128×128 RGBA32 без mipmap, **24,5 MiB данных текстур**. CPU-копии готовых текстур отпускаются. Это расчёт текстур, не замер общей памяти или пика.

Core и TracksV3 имеют **те же SHA-256**, что в [полном отчёте 3.0.0](v3-full-independent-results.txt); доставка независимо сверила оба. Повтор тысяч проверок неизменённой механики не выполнялся. Прежние PASS engine 12/865, геометрии 22400/976 и независимых проб сохраняют применимость.

Новый [аудит UI](v3-visual-ui-review.txt): **558 проверок**, включая базовые 120, при 1280×720 / 844×390 / 568×320 и DPR1/2. Дополнительная целевая проверка финального сдвига на 5 px подтвердила положение кнопки над декоративной землёй. Это проверка геометрии и обработки ввода с заглушками Unity, не физический multitouch.

[v3-visual-pause.json](v3-visual-pause.json) содержит `desktopDuringPause` и подтверждает заморозку в desktop viewport. Прежняя ошибочная подпись исправлена; этот файл **не используется как доказательство поворота**. Для ориентации используется только отдельный `v3-visual-orientation.json` с записанными DOM-размерами. Проверка поворота началась с уже поставленной паузы и подтверждает сохранение состояния при смене ориентации/возврате, а не отдельное автоматическое срабатывание паузы из движения.
