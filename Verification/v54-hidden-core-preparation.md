## Точки интеграции после разрешения

- Состояние общее для заезда, Track — неизменяемые данные. Предложены Hidden/Warning/Solid, RevealedAt/SolidAt, TriggerPlayerId; GetPhase для обычного препятствия возвращает Solid.
- Retry находится в RaceSimulation.Press около строки 553: состояния раскрытия сбрасываются, выбранная длительность предупреждения сохраняется.
- Фильтровать и NextCollision, и NextLanding. Отключение одного удара оставит невидимую посадку.
- Общий scheduler должен разделять продвижение по границам reveal/deadline/body-clear/terminal, учитывая реальную скорость, эффекты и состояние всех активных участников. Изученный вариант — аналитический AdvancePlayer на независимом snapshot, без изменений живого мира при прогнозе. Реализация ещё не выбрана и не проверена.
- На границе освобождения нельзя создавать новый удар уходящему телу; последующий возврат должен сталкиваться обычно. Воздух сам по себе не задерживает solid.
- Снимок глубоко копирует mutable dictionary/states. Смена значения предупреждения разрешена до старта; ровно пять значений из контракта.

## Будущие целевые проверки

Пять длительностей; разные dt; 2–4 участника и перестановка массива; первый/отстающий участник; настоящее ускорение; горизонтальное и вертикальное освобождение объёма; recovering/terminal; pause без Advance; retry; независимость snapshot; реальный удар после активации; прежние обе части ворот и профили без изменений.
