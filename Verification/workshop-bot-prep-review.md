# Workshop 0.5: независимое ревью подготовки бота

5 ноября 2026. Исполнитель: **Sol / high**. STATUS: [WORKSHOP-BOT-PREP-STATUS.md](WORKSHOP-BOT-PREP-STATUS.md). Основа Git `7389537`, проверено рабочее дерево поставки 0.5, включая ещё не закоммиченные изменения.

## Область и итог

Проверены чужие изменения: `BotPreparationSearch`, `BotPreparationService`, `Program`, `ServerOptions`, `PreparedReferenceProof`, `TrackCatalog`, `StochasticTrackMap`, `StochasticBotSettings`, связанный конструктор/проверка Мастера и `JsonTracksPresentation.VerifyImportedReferences`. Собственные изменения Web UI и автосохранения не включены в это независимое ревью.

**Оставшихся материальных блокеров по прочитанному коду не обнаружено.** Обнаруженная ошибка обработки некорректной подсказки передана владельцу и исправлена; её новый тест должен входить в финальный прогон владельца. Ревью не заменяет итоговые тесты, Unity/WebGL, проверку браузера, сборки и архива, которые ведёт координатор.

## Исправленное замечание

`BotPreparationService.ReadGeometry`: запасное чтение устаревших `botReferences` вызывало `GetValue<double>()` у `null`. Валидная геометрия с `botReferences: [{"profileId":"Chosen","inputs":[null]}]` приводила к `NullReferenceException`, то есть HTTP 500 вместо игнорирования непригодной подсказки и обычного ограниченного поиска. Владелец добавил проверку `inputs.Any(n => n == null)` перед извлечением значений и целевой регрессионный сценарий в `PreparationTests/Program.cs`. Исправление и наличие теста просмотрены; отдельно повторный поиск ревьюером не запускался.

## Проверенные свойства

- **Запрос и ресурсы.** Тело ограничено Kestrel 16 МиБ; вложенный исходный JSON — 2 МиБ; подсказка — 4096 конечных строго возрастающих неотрицательных X. Профили ограничены двумя известными без повторов. Выходной ID нормализуется строгим `TrackJson`; встроенные и исторические ID отклоняются. Подготовка входит в общий fail-fast semaphore до связывания тела; HTTP 429 содержит `Retry-After`. Маршрут с другим регистром и завершающим `/` включён в эту границу.
- **Конечный поиск и отмена.** API задаёт 180 000 расширений / 8 секунд на поиск профиля, beam 128; проверка профиля ограничена общим временем 20 секунд и 100 000 шагов. Это проверки между атомарными операциями симуляции, а не жёсткое прерывание посреди Core. `RequestAborted` передаётся из endpoint в сервис/поиск, проверяется между proof-срезами; lease освобождается в `finally`. Пустой или ошибочный seed не является условием поиска. Неуспех возвращает `not-found`/`unsupported`, без утверждения непроходимости или оптимальности.
- **Реальные награды.** Поисковый свидетель требует чистого финиша, отсутствия ловушек/срывов, полного финишного рывка и завершённых обычных эффектов. Экспорт строит IDs из фактически успешных положительных зон. Строгий JSON проверяет набор IDs, единственный финиш, B полных эффектов и хеш. Общий proof затем независимо исполняет дистанционный ввод в production SOLO: точный набор IDs, все нажатия, отсутствие активных/ожидающих эффектов, фактические B и время финиша.
- **Мастер и предупреждения.** Тот же proof запускает настоящий `StochasticBotController` через request-local `CreateProofMaster`, без установки каталога. Для выбранных таймеров скрытой карты проверяются все пять значений, для authored — собственные таймеры. Условия Мастера сохраняют действующий [BOT-контракт](../../flip-race/docs/features/bot-play.md): успех выбранных IDs, достаточный общий счётчик завершённых обычных эффектов, чистый финиш и полный финишный рывок. Дополнительный положительный бонус сам по себе не отвергает маршрут.
- **Доверие и изоляция.** Workshop не вызывает `TryInstallBuiltIns`/`TryImportLocal`, использует отдельные геометрию, эталоны и proof каждого запроса. `TrackCatalog` допускает BOT локальной карты только после успешного proof выбранного профиля; совпавший хеш файла сам по себе не даёт допуск. Перед использованием перепроверяются текущая геометрия, профиль, входы, выбранные IDs и B. Подмена/изменение данных после proof снимает допуск. У встроенных 15 сочетаний остаётся прежний путь получения эталона.
- **Импорт и интерфейс игры.** Карта добавляется для людей до проверки BOT. Coroutine выполняет `Step(1)` в срезе около 4 мс и делает `yield return null`; отказ proof оставляет человеческие режимы. Предел Core — 200 000 шагов и 120 секунд каждого забега. Один атомарный шаг контроллера может превысить 4 мс: фактическая плавность проверяется в итоговой игре, статическое ревью её не доказывает.

## Принятые ограничения

- Мастер использует общий счётчик завершённых импульсов: отдельного доказательства обслуживания выбранного эффекта по каждому ID нет. Это существующий явно описанный контракт, подтверждённый координатором в этой поставке; точный эталон проверяется строже. Изменение этого правила не включено в ревью как требование.
- Beam-прореживание, конечный бюджет и короткий хвост улучшения не гарантируют нахождение любого существующего пути, сбор всех альтернатив, оптимум или интересность трассы.
- Изоляция запросов и защита от поддельного хеша проверены чтением кода и наличием целевых тестов; итоговый запуск этих тестов принадлежит владельцам. Новую полную матрицу ревьюер не запускал и не заявляет.
