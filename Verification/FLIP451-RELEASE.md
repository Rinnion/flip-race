# 4.5.1-trial — один воздушный повтор у Быстрого переворота

19 октября 2026. **Целевые проверки 4.5.1 PASS:** исходники, сохранённая 4.5.0, тесты, Web, настройки/один повтор в браузере и безопасный заезд из нового ZIP. Ограничение: в двух нативных full-попытках финальная цель пропущена; браузерный результат 33,2 с для этой версии не подтверждён. Это узкая правка готового профиля, без нового подбора геометрии или окон ввода. Исторические MODES-отчёты не переписываются.

## Контракт изменения

У `FlightPresets.FastFlip` воздушные повторы изменены с 0 на 1. Первое действие остаётся Flip, закон Gravity, тяга 2700, толчок 35; неактивные jump 300, linear speed 530 и height 112 сохранены. Один повтор в воздухе меняет направление тяги, сохраняя текущую скорость; следующий воздушный тап до восстановления заряда не действует. Сам алгоритм повтора/посадки не менялся.

Готовый ID 11 и reset к нему получают новый профиль с одним повтором. Сохранённый custom с явно записанным 0 продолжает означать 0; выбор готового профиля не переписывает custom. Основной ID 10 остаётся Jump 350 / g 662,5 / ∞.

Сравнение с исходным HEAD `4dbab9433b9dd1403e3415ca5b47d1d5d3ba1a8d` подтвердило ровно две замены в этих production-файлах:

| Файл | Проверено |
|---|---|
| `FlightSettings.cs` | Только `FastFlip`: `AirRepeatLimit.None` → `One`; остальные поля и presets побайтово эквивалентны после нормализации перевода строк |
| `TracksFull.cs` | Только условие выбора Fast-маршрута: повтор 1 вместо 0. Все координаты, размеры, кольца, массивы маршрутов и finish неизменны |
| `RaceSimulation.cs` | Не менялся; проверка доступного заряда, расход одного повтора и восстановление на опоре прежние |
| `FlightSettingsStore.cs` | Не менялся; decoder читает сохранённый repeat как физическое значение, preset 11 отдельно ссылается на FastFlip |

[Машиночитаемый audit/SHA](flip451-source-audit.json). Это проверка source-delta, не замена целевым исполняемым тестам и браузеру. Изменение route guard выбирает прежние авторские Fast-массивы для нового готового профиля; оно не меняет custom-физику.

Обновление того же browser origin с 4.5.0 сохранило explicit custom 0 и обновило готовый Fast до One. Применение/reload custom, Edit Fast и Reset к нему проверены. Реальные A/L подтвердили один принятый повтор, отклонение следующего, независимость игроков и восстановление заряда после посадки.
