# Мастерская 0.5.21: анализ всех манёвров

Статус: принято и выпущено. 16 ноября 2026. Ветка `experiment/workshop-analysis-0.5.17`, база `d656843` (0.5.20). Основной checkout Unity и прежние сборки сохраняются.

Источник: пользователь просит считать матрицы всех манёвров выбранного прохождения, подсвечивать трудные места по доле зелёных клеток, сохранять результаты в JSON карты и повысить версию; уточнение — диапазон 600 мс. Принято: −600…+600 мс, шаг 50 мс.

| ID | Критерий | Владелец | Состояние |
| --- | --- | --- | --- |
| ALL | Все команды выбранного прохождения; одинаковые пары без повторов, перекрывающиеся соседние пары длинного полёта отдельно | Backend | Принято |
| GRID | 625 клеток пары / 25 одиночных; существующие физические критерии | Backend | Принято |
| MAP | Доля зелёных от всех клеток; плавная шкала и точный процент; незавершённые нейтральны | UI | Принято |
| SAVE | Версионные результаты в JSON, привязанные к геометрии, настройкам и ленте; восстановление матриц, сохранение поиска маршрутов | Backend/UI | Принято |
| UX | Прогресс, отмена, выбор матрицы и автоматический просмотр альтернативы | UI | Принято |
| RELEASE | 0.5.21, проверки .NET/Web/HTTP/браузер, пакеты и документация | Root | Принято |

Затронут WORKSHOP; сохранение CONTROL, TRACKFILE, SURFACE-RUN: Core, управление, настройки разгона, поисковая сетка и геометрия не меняются. Полёт определяется существующим AnalysisTarget. Исходная лента и путь не заменяются пробами. Одиночная ручная проверка сохраняет диапазон по умолчанию ±300 мс.

Решение о представлении: Astra/high; backend и UI: Sol/high. Шкала характеризует локальный допуск в исследованной сетке, не вероятность прохождения человеком. Серые, отклонённые и завершённые с неопределённым физическим исходом клетки входят в знаменатель; ожидающие вычисления требуют нейтрального статуса. Пропуск нажатия не входит в долю.

- HTTP [net8](workshop-batch-http-net8.json) и [net10](workshop-batch-http-net10.json) на финальных пакетах: JSON round-trip, сохранность геометрии/расширений, совпадение replay до/после записи, восстановление без вычислений, частичные checkpoints и продолжение, устаревание геометрии, соседние пары. По 29 smoke-запросов ([net8](workshop-batch-smoke-net8.json), [net10](workshop-batch-smoke-net10.json)); [77 проверок серверной политики](workshop-batch-policy-net10.json). - Независимое ревью Sol/high: исправлены повтор checkpoint при продолжении, обработка повреждённого GZip и ожидание освобождения вычислительного слота после отмены. Открытых замечаний нет.
- Браузер: «Передумай», Основной без разгона, `[1.65,4.15,4.25]`: одиночный манёвр 15/25 (60%), пара 149/625 (23,84%). Выбор пары открыл 625 клеток; −100/−50 сразу показал альтернативу с двумя нажатиями. Смена управления убрала подсветку; восстановление вернуло Основной и прежние матрицы.
- Скачанный через «Файл» JSON открыт в свежей вкладке финального пакета 4236. Восстановление вернуло ленту/настройки и матрицы без общего расчёта. Одиночная строка имеет 25 клеток; −600 мс показал удар и отдельную линию. Изменение длины 7920→8000 убрало отметки и пометило данные устаревшими; undo/восстановление вернули их. Ошибок консоли нет. [Скриншот](workshop-batch-0521.jpg).

Хранится последний пакет выбранного прохождения; поисковые группы настроек сохраняются. Полные матрицы сжаты в JSON, при лимите 2 МиБ выводится частичное сохранение. Проба Мастера для отдельного подготовленного JSON требует сначала выбрать прохождение текущей карты. Отмена сохраняет доставленные результаты, а не прерванную посередине клетку. Общая человеческая сложность трассы этой метрикой не объявляется.

Обязательных следующих действий и нерешённых блокеров нет.
