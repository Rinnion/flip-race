# R7: активация каталога и UI

20 октября 2026. После overall GO независимого R7-аудита активирован `TracksRhythm.All`: Каскад, Плотный поток, Волны. `RaceTracks.All` содержит три прежние трассы, затем три новые. Короткая проба ворот остаётся отдельным седьмым пунктом в прежних участках. Геометрия R7 и Presentation при активации не изменялись.

**PASS: 940 проверок** actual-catalogue UI. Production `FullTrackRect`, `OldTrackRect` и `FlightPointer` проверены при 568×320, 844×390, 1280×720. Тест использует настоящие шесть ID, порядок и `Get`, проверяет 9 обычных наград + 1 finish + 2 negative у каждой трассы, непустые описания, размеры и непересечение карточек с нижней кнопкой/возвратом.

Центр и углы каждой полной карточки проверены для preset10, preset11 и custom. Меняется только выбранный в меню ID; сохранены preset/custom-значения, активный Game, герои 2/3 и состояние готовности. Нажатие в зазор между колонками ничего не выбирает и не запускает. Полная .NET-компиляция Core/Presentation/Web: **0 ошибок, 0 предупреждений**.

Это проверка production-геометрии меню и обработчика, без native Unity lifecycle, рендера и браузерного ввода. Финальная браузерная проверка отдельна. По коду открытие меню устанавливает paused, а HTML fullscreen-кнопка скрывается при этом состоянии; copy-overlay видим только на странице редактора настроек.
