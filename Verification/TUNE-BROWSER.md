# 4.1.0-trial: браузер и поставка

Проверено 16 октября 2026 года. **G3 PASS.** Финальная WebGL-сборка запущена на [localhost:4184](http://127.0.0.1:4184/). Сначала отдельно проверены профили на свободном участке в `4.1.0-controls`, затем реализованы мгновенные ускорители, проверена геометрия и собрана `4.1.0-trial`.

## Реальные заезды

Ввод выполнен клавишами A/L и кликами по видимым элементам canvas. Состояние читалось из публичного `data-flip-state`; команды в Unity или подстановка состояния не использовались. Расстояния нажатий взяты из проверенных маршрутов `TracksTune`, продвижение учитывает настоящую скорость с эффектами.

| Профиль | Безопасный путь, оба игрока | Идеальный путь, оба игрока | Размер окна |
|---|---|---|---|
| База | 21,0 с; 0 бонусов, 0 ударов | 19,2 с; 6 плюсов / 3 мгновенных, 0 минусов, 0 ударов | 1280×720 |
| Сильнее тяга | 21,0 с; 0 бонусов, 0 ударов | 19,2 с; 6 плюсов / 3 мгновенных, 0 минусов, 0 ударов | 1280×720 |
| Толчок | 21,0 с; 0 бонусов, 0 ударов | 19,2 с; 6 плюсов / 3 мгновенных, 0 минусов, 0 ударов | 1280×720 |
| Тяга + толчок | 21,0 с; 0 бонусов, 0 ударов | 19,2 с; 6 плюсов / 3 мгновенных, 0 минусов, 0 ударов | 844×390 |

Все успешные заезды заканчиваются с нулевыми остатками boost/slow и пустой очередью. Безопасные маршруты не используют воздушных повторов. Дополнительно:

- **Ловушка, combined, 844×390:** оба 19,8 с, 5 плюсов / 3 мгновенных / 1 минус, без ударов.
- **Обгон последней молнией, base, 844×390:** одинаковые первые 11 нажатий; первый игрок выполняет последний манёвр и получает все 6 плюсов за **19,2 с**, второй пропускает только последний бонус и финиширует с 5 плюсами за **19,5 с**. Оба без ударов; победитель первый. Это разница фактического пересечения финиша.
- Реванши между заездами сохраняют профиль и сбрасывают награды/движение.

[Полная трассировка](tune-challenge-browser-trace.json.gz) содержит 10 успешных заездов и одну неудачную автоматическую попытку combined. В последней между наблюдениями был разрыв **2,562 с**: ввод для x=2957,1 поступил при x=3277,56; результат 21 с / 5 плюсов / 3 удара у обоих. Попытка сохранена в журнале. Повтор с тем же маршрутом и сборкой прошёл за 19,2 с без ошибок. В отчёте геометрии отдельно указаны реальные игровые окна: индивидуальные ±40 мс проверены; это не обещание переносимости произвольного одновременного разброса всех нажатий.

## Интерфейс

- Постоянный `v4.1.0-trial` рядом с «флип!» виден при готовности, гонке, результатах, открытом меню, правилах, паузе и портретном предупреждении. Значение берётся из `Application.version`.
- В меню четыре профиля и два прежних режима. Выбор общий для двоих; готовность очищается, остаточный клик не начинает игру.
- Герои `[3,2]` сохраняются при смене профиля. Переход Gravity → старый `v4-challenge`, Base → новый `v4-tune` подтверждён; свободный участок остаётся общим.
- Мгновенный бонус отличается бирюзовым шестиугольником с молнией; подбор даёт вспышку, след и сообщение «Молния! Скорость ×1,5». Полёт сохраняет траекторию, ускоряется продвижение.
- На мобильном реванше клик верхнего игрока даёт готовность `[true,false]`; после нижнего начинается countdown с нулевыми бонусами, ударами и расстояниями. Пауза сохраняет состояние. После поворота в 390×844 виден экран поворота и номер версии.
- После проверки возвращены базовый свободный участок, исходные герои и обычный размер окна. Пользовательская вкладка с предыдущей игрой не перезагружалась; новая сборка оставлена отдельной вкладкой.
- Консоль финальной вкладки: **0 warning / error**.

[Данные проверок интерфейса](tune-ui-browser-checks.json). Размеры мобильного окна проверены в desktop-браузере; физический мультитач, реальное мобильное устройство и iframe itch.io этим не подтверждаются.
