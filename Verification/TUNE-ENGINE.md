# TUNE-01/02: профили и мгновенные ускорители

Проверено 16 октября 2026. Этапы выполнены последовательно: сначала профили и их тесты, затем неизменный runtime первой браузерной сборки, после её подтверждения — мгновенные ускорители. Геометрия `TracksV4`, старые трассы и UI этой подзадачей не изменялись. Unity параллельно основной задаче не запускался.

## Четыре профиля

| API / ID | Название | Ускорение, единиц/с² | Начальный толчок, единиц/с | Обычный перелёт |
|---|---|---:|---:|---:|
| `MotionProfiles.Baseline` / `base` | База | 662,5 | 0 | 0,8000000000 с |
| `MotionProfiles.StrongGravity` / `gravity` | Сильнее тяга | 1000 | 0 | 0,6511528238 с |
| `MotionProfiles.Impulse` / `impulse` | Толчок | 662,5 | 140 | 0,6161189478 с |
| `MotionProfiles.Combined` / `combined` | Тяга + толчок | 1000 | 140 | 0,5260330322 с |

`MotionProfile` неизменяемый: `Id`, `Name`, `GravityAcceleration`, `DepartureImpulse` — readonly. `MotionProfiles.All` содержит четыре варианта, `Get(id)` возвращает выбранный. `GameState.Profile` по умолчанию равен `Baseline`. `CreateTrial(track, motion, profile = null)` сохраняет поведение прежних вызовов; обычный `CreateGame` и линейное движение остаются прежними.

Толчок применяется только при новом отрыве с поверхности. Воздушный повтор сохраняет входящую скорость и меняет знак ускорения. При случайном касании противоположной поверхности скорость обнуляется, затем герой уходит с неё из покоя под действием выбранной гравитации: нового толчка или заряда нет. Оба направления используют один профиль. Разгон, поверхности, разворот скорости, непрерывные столкновения и кольца используют его параметры согласованно.

TUNE-01: **6 сценариев / 432 проверки**, независимый аналитический аудит — **14 649**. Проверены оба направления, посадки, ранний и поздний повтор, отсутствие лишнего толчка, касательные кольца, края камней, пауза, восстановление, snapshot и реванш. ## Мгновенный эффект и учёт времени

`RiskZone.Kind="instant"` и `IsInstant` обозначают отдельный положительный предмет. Он подтверждает награду сразу при геометрическом контакте, независимо от `FreeReward`, связанного камня или окончания полёта. Каждый игрок получает его один раз. `InstantBoostsEarned` — подмножество общего `BoostsEarned`; `LastInstant` содержит время и ID контакта. `LastSuccess` также обновляется этим положительным событием.

- Без активного эффекта instant сразу включает скорость 330 на 0,6 с.
- При активном ускорении добавляет ещё 0,6 с к его оставшейся длительности, сохраняя уже отработанное время. Множитель остаётся 1,5.
- При активном замедлении немедленно включает ускорение, а тот же остаток замедления помещает первым перед ранее ожидавшими эффектами. После рывка возобновляется остаток, а не новое полное замедление.
- Обычные положительные и отрицательные награды сохраняют FIFO. Instant не даёт защиты от камня; восстановление замораживает активный эффект, приостановленный остаток и очередь.

`SpeedEffect.PulseCount` по умолчанию 1; `CompletedPulses` — число уже полностью отработанных частей по 0,6 с внутри этого эффекта. `Duration` равна суммарной длительности. При продлении `Elapsed` не сбрасывается. Общие `CompletedBoosts`/`CompletedSlows` получают одну запись за каждую фактически завершённую часть, даже если продлённое ускорение ещё активно.

`BoostElapsed`/`SlowElapsed` суммируют ещё не переведённое в полные записи отработанное время активного и ожидающих эффектов. Поэтому приостановленные 0,2 с замедления не теряются и не учитываются дважды после возобновления. `BoostRemaining`/`SlowRemaining` по-прежнему показывают только активный знак для графики.

Контрольный пример без ручного заполнения состояния: трасса 55 единиц, замедление с x=0, instant при x=22. Первые 0,2 с проходят со скоростью 110, следующие 0,1 с — со скоростью 330. Физический и расчётный финиши равны **0,3 с**. Остаток замедления 0,4 с остаётся в очереди, но уже отработанные 0,2 с участвуют в времени финиша. До реализации красный тест показывал скорость 110 и instant в очереди.

Snapshot должен копировать `GameState.Profile` как неизменяемую ссылку; у каждого `SpeedEffect` — также `PulseCount` и `CompletedPulses`; у игрока — `InstantBoostsEarned` и `LastInstant`. Прежние правила копирования остальных полей, множеств и очереди сохраняются. Реванш очищает новые состояния вместе с остальными, сохраняя профиль и героя.
