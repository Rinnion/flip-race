# V4-01–02: отдельная проба управления

Проверено 16 октября 2026. Сначала V4-01 прошёл **7 сценариев / 151 утверждение**, затем был включён воздушный повтор и V4-01/02 вместе прошли **13 сценариев / 289 утверждений**. Эта контрольная точка сохранена в [v4-engine-tests.txt](v4-engine-tests.txt). После добавления проверки связанных колец при гравитационном возврате основной набор прошёл **14 сценариев / 310 утверждений**; текущий stdout — [v4-engine-latest-run.txt](v4-engine-latest-run.txt). Runtime между этими двумя запусками не менялся. Независимый аудит и браузерная проверка фиксируются отдельно.

Обычный `CreateGame` не изменён: версия 3.0.1 и её трассы используют `MotionMode.Linear`. Новые режимы доступны только через `CreateTrial(track, motion)`, который создаёт состояние готовности с `Mode="trial"`:

- `Linear` — прежний линейный перелёт 0,8 с, ввод в воздухе отклоняется.
- `Gravity` — разгон к поверхности из покоя, ввод в воздухе отклоняется.
- `GravityAirFlip` — тот же разгон и одно переключение гравитации в воздухе с сохранением текущей скорости.

`GameState.Motion` хранит выбранный режим. `PlayerState.VerticalSpeed` измеряется в мировых единицах/с; `Gravity` равна +1 к полу и −1 к потолку; `AirFlipAvailable` обозначает оставшийся повтор. `Y` сохраняет прежнюю нормализацию 0..1, `Flipping` означает незавершённый полёт. В гравитационных режимах `FlipElapsed` считает фактическое время полёта и не ограничивается 0,8 с; `FlipTo` показывает текущую выбранную поверхность.

## Модель и события

Ускорение — 662,5 единицы/с², расстояние между положениями центра — 212 единиц. Обычный перелёт из покоя поэтому длится ровно 0,8 с. Положение вычисляется как `y + vy*t + a*t²/2`, скорость — `vy + a*t`. Горизонтальное движение и FIFO ускорений/замедлений сохраняются.

На поверхности гравитационной стороны вертикальная скорость обнуляется, полёт завершается, повтор восстанавливается только для `GravityAirFlip`. При касании противоположной поверхности скорость тоже обнуляется, но полёт и потраченный заряд сохраняются: гравитация уводит героя обратно. Удар о камень замораживает положение, скорость, гравитацию, возраст полёта и очередь на прежние 0,5 с; само восстановление не выдаёт заряд.

Симуляция делит шаг на события поверхности, разворота вертикальной скорости, контакта камня/кольца, начала/конца эффекта и финиша. Пересечения с расширенными границами препятствий находятся по квадратному уравнению, в общем горизонтальном интервале контакта. Для кольца расстояние до параболы даёт многочлен четвёртой степени. `ContinuousMotion` изолирует его корни по корням производной и уточняет каждый монотонный интервал бисекцией до 1e−12 с; касательные корни без смены знака включаются. Это непрерывный поиск событий, а не выборка положения через кадры. Предварительное горизонтальное отсечение оставляет только область возле кольца.

`RiskZone.FreeReward=true` подтверждает положительную награду сразу при геометрическом касании, даже в незавершённом полёте. Последующий удар её не отменяет. Старые связанные кольца оставлены с `FreeReward=false`: нужно пройти связанный камень без удара. Для `Placement="after"` подтверждение дополнительно ждёт реальной посадки, а не старого таймера. Возврат на исходную поверхность может быть такой посадкой. Отрицательные кольца по-прежнему срабатывают сразу и один раз для каждого игрока.

## Проверенные случаи

- Разгон: через 0,2 с центр находится на 212,75, скорость −132,5; через 0,4 с центр на 173, скорость −265; через 0,8 с — посадка на потолок. Линейный контроль на 0,4 с остаётся на 120.
- Контакты с горизонтальным и вертикальным краями камня, очень узким камнем, большие шаги, точные границы поверхностей, заморозка ненулевой скорости при ударе.
- Касательное касание кольца точно на 0,4 с, соседний промах на 0,001 единицы, контакт на конце шага, немедленная свободная награда и отменяемая связанная награда.
- Повтор на 0,2 с возвращает на исходную поверхность на 0,682842712… с; повтор на 0,4 с — на 1,365685425… с. Герой сначала продолжает движение по инерции, затем разворачивается. Третье нажатие до посадки отклоняется.
- Поздний повтор на 0,6 с приводит к касанию противоположного потолка на 0,917157288… с без восстановления заряда, затем к посадке на пол ещё через 0,8 с. Поздняя коррекция перед камнем действительно может закончиться ударом.
- Кольцо с четырьмя корнями контакта: вход, выход возле вершины параболы и повторный вход на возврате. Награда выдаётся один раз; активное замедление и ожидающее ускорение отрабатывают полностью, заряд не восстанавливают.
- Связанное кольцо после камня при новом разгоне: безопасный возврат ждёт реальной посадки после `ClearX`; ранний возврат сначала касается кольца, затем заднего края и отменяет награду. Воздушный повтор на 0,46 с оставляет награду неподтверждённой после старых 0,8 с и подтверждает её при реальном возврате на исходный пол на 1,570538239… с.
- 30/60/144 Гц, шаги 0,317, 2,5 и 100 с; фактические финиши и точные ничьи; финиш посреди незавершённого полёта; независимость игроков, четыре равных героя, пауза и полный сброс на реванше.

Старая регрессия также проходит: V1 **13/13 / 963 утверждения**, V2 **12 / 3554**, V3 **12 / 865**; JS differential — **40 228 снимков / 1 448 208 полей**, численная погрешность строго меньше 1e−8. Это подтверждает сохранение линейной версии, а не перенос полной геометрии v3 на новое управление.

## Запуск

Из корня проекта:

```powershell
dotnet run --project Tools/ParityRunner/ParityRunner.csproj -- Tools/engine-parity-fixtures.tsv.gz
```

В Unity используется прежнее меню **Flip Race → Run engine parity tests** или `-executeMethod FlipRace.Editor.EngineParityTests.Run`. `EngineV4Tests.RunAll()` включён в оба runner. `.meta` для `ContinuousMotion.cs` и `EngineV4Tests.cs` присутствуют. В этом этапе Unity параллельно основной сборке не запускался, полные трассы и их геометрия не менялись.

Хеши исходников контрольной точки приведены в текстовом выводе. Дальнейшая геометрия короткого участка и браузерный выбор настроек относятся к V4-03/04; расширение на полные трассы V4-05 этим отчётом не объявляется завершённым.

Независимый G1/G2 аудит завершил **7836 проверок** (954 + 6750 + 132 связанных возврата) без блокирующих замечаний. Последние 132 проверки дополнительно подтверждают ожидание посадки после заднего края, позднее касание противоположного потолка без подтверждения награды и раннее касание кольца с последующим ударом и отменой награды; проверены все шесть размеров шага. На точном двойном корне касания поверхности при повторе в `sqrt(0,32)` и шаге 1/30 с отмечена численная погрешность: событие примерно на 3,1e−8 с раньше, остаточная скорость около 2,07e−5 единиц/с в математический момент вершины. Направление, заряд и дальнейший возврат верны; расхождение положения меньше 1e−4 мировой единицы. Ради этой неблокирующей погрешности runtime не изменялся.
