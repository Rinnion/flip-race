## Аналитические ориентиры

Выбранный профиль: FirstAction Jump, Gravity, Unlimited; u350ед/с, g662,5ед/с². Без воздушного ввода вершина наступает через **0,5283018867924528с**, высота **92,45283018867924ед**, возврат на ту же стену через **1,0566037735849056с**. Повтор меняет только знак тяги и сохраняет текущую скорость; неограниченная серия отдельных нажатий не имеет искусственного лимита.

Для немаркированного камня на исходной стене подъём центра над исходной опорой должен превышать высоту камня всё время прохождения его расширенного горизонтального интервала. С радиусом игрока14 ширина64 требует92ед, ширина200 —228ед. Интервал выше высоты h равен `2*sqrt(350²−2*662.5*h)/662.5`.

| 48 |0,7326587834с|161,1849323|241,7773985|Один прыжок проходит64×48 при правильно выбранном старте |

Максимальная высота немного больше92, поэтому **сравнения высот недостаточно** для второго утверждения. Нужны непрерывный контакт и фактическая длительность прохода ширины. При изменении скорости внутри пролёта отдельный сценарий проверяет реальную интеграцию; таблица относится к постоянным220/330.

После центральной посадки на камень64 до конца опоры остаётся32/330=**0,096969697с**. Это меньше150мс реакции: корректный обязательный выход должен допускать естественный сход и дальнейшую воздушную коррекцию, а не требовать мгновенного нового прыжка после визуального подтверждения.

## TRACKS-01

| Группа | Независимая проверка |
|---|---|
| Профиль | Точные публичные поля `FlightPresets.Chosen`; старые presets неизменны; зеркало пола/потолка и оба игрока; измерение реального полного прыжка; серия воздушных Press без нового импульса |
| Малый/высокий камень | Реальный одиночный Press, аналитически центрированный проход, обе стены,220/330; успешный64×48, контакт64×92/200×92. Скорость330 получена настоящими instant-наградами, не подстановкой поля игрока |
| Метка64 | ЦентрX+32, ширина24–32, края включительно и±малый epsilon снаружи; фактическая плоскость камня, боковой ранний контакт не подменяется landing; зеркальная посадка между кадрами |
| Опора и край | Нажатие непосредственно до trailing edge — новый прыжок350; непосредственно после — смена тяги с сохранением VY. Сход без импульса; нет повторного столкновения с покинутой гранью/нулевого цикла. Повторная посадка допустима без повторной награды |
| Цепочка | Полный сбор с учётом ускорения первого; только первый/только второй/ни одного; отдельные IDs и одна награда на ID; потеря первого не отключает второй. Ordinary/slow заканчиваются внутри интервала между кольцами без потери времени/эффекта |
| Стыки | Landing+reward+edge и окончание эффекта на одном шаге, большая dt; contact/side impact, сохранение остальных препятствий; pause/recovery замораживают полёт/очередь вместе с движением |
| Авторский участок | Реальные SafeRoute/RiskRoute и намеренный промах/ошибка, без изменения старта игрока; правильное число наград/ударов и отсутствие оставшихся effects у финиша |

Шаги:1/30,1/60,1/144,0,317,2,5 и100с; адаптивное разбиение только по фактической доступной скорости/окончанию эффекта и запланированному моменту ввода. Аналитический oracle не вызывает production-предикторы столкновений. Для зеркальной подготовки потолка используются реальные прыжок и воздушный повтор выбранного профиля; состояние игрока не подставляется.

## Три полные трассы

- Проверить7920, уникальные IDs, точный бюджет: linked before/after по одному, свободных instant два, цепочка из двух, landing три (два64 и одна200×92), отрицательных два, finish один приX7876; положительных всего10.
- Safe36,0/0 наград/0 hits; full33,2/9 ordinary+1 finish/0−/0 hits; намеренная ловушка и возможность продолжить. Проверить назначения игроков и асимметрию только финальной цели:33,2 против33,3 при одинаковом предыдущем маршруте.
- Пропуск каждого кольца цепочки не отменяет другое; собрать все плюсы одновременно действительно возможно. Низкие кольца не касаются бегущего по стене героя случайно. На каждой трассе есть полосыY≈195–200,120,60, дополнительно осмысленные зеркала.
- Измерить окна в реальном времени, включая330/110 и смену скорости внутри связки. Безопасные обязательные отдельные вводы/локальные группы: цель±60мс; reward/finish могут быть уже, точное значение записать. Не объявлять устойчивость всех независимых одновременных ошибок.
- После выбранных реальных ошибок остановить номинальный сценарий, отработать остаток recovery и150мс реакции; попробовать только доступные реальные действия и явно достичь следующей trailing границы без ещё одного удара. Это ограниченная выборка состояний, не доказательство восстановления из любого состояния.
- Чистый подход кX7876: вывести bound по последнему достижимому месту награды и максимуму оставшихся длительностей, включая отрицательные/приостановленные эффекты. Наличие пустой очереди только в ideal недостаточно. После finish-plane нет препятствий/наград; actual finish и ledger согласованы без коррекции подписи времени.

## Мобильный обзор и UI

Read-only вычислить видимый world-интервал из реального scaleX/камеры при568×320. У первого обязательного действия каждая ближайшая связка целиком видима, включая второе кольцо цепочки и ловушку. Оценка учитывает радиусы/ширину объектов и ускорение, а не только центры. Коридоры проверяются в локальных координатах обоих игроков; screenshots и реальные заезды подтверждает отдельный browser gate.

Карточки героев: ширина и высота≥44CSSpx при568×320, ориентир48; рисунок и hit-testing совпадают с DPR/поворотом верхней половины. Центр/края всех4 кнопок обоим игрокам, зазоры и промахи, одинаковые герои, сброс собственной ready при смене. Выбор героя и любой промах рядом не должны подтверждать ready; готовность имеет отдельную явную область.

Новый крупный ассет имеет отдельную текстуру/генератор и кэш, не растянутый стандартный рисунок. Нужны floor/ceiling, actual200×92, совпадающая грань/метка, отсутствие перекрытия колец. Визуальная проверка не заменяется численной.
