Каталитик принял первый этап по запросу пользователя: существующие трассы в JSON, загрузка штатного каталога по URL, импорт локального файла и инструкция. ## Результат

Восемь полных трасс читаются из `StreamingAssets/Tracks/index.json` и перечисленных файлов. Источник для следующих сборок — `Assets/StreamingAssets/Tracks`; сборка не запускает генератор C# и не перезаписывает авторские JSON. Загрузка атомарная: ошибка не превращается в незаметный запуск прежней C#-карты. Исторические учебные участки и автономные проверки остаются отдельными C#-путями.

В каталоге восемь карт на страницу, девятая ячейка — «Импорт JSON». Настоящий выбор файла добавляет карту только в текущую сессию, выделяет её и открывает нужную страницу. Он не меняет режим или управление. Неправильный файл и занятый ID не подменяют текущую карту. Импортированные карты доступны людям; BOT требует подготовленных данных штатного каталога и совпадения фактического содержимого/профиля. Файл с локально заявленными эталонами сам не получает доверие BOT.

Редактор/визуализатор, подготовка новых эталонов, произвольный удалённый URL и постоянная браузерная библиотека в этот этап не входят. Готовый импортируемый пример: [Моя трасса](../Tools/TrackCatalogExport/Samples/my-mixed-track.json). Геометрия примера совпадает с Полосой уловок; ID и название новые, эталоны удалены.

## Проверка настоящего WebGL

В in-app browser открыта реальная WebGL, не HTML-макет. Выполнены:

1. Старт с восемью JSON-картами и видимой версией 5.4.3-trial. Установлен явный ready после загрузки каталога.
2. Кнопка «Импорт JSON» открыла настоящий file chooser; выбран `my-mixed-track.json`. Получены сообщение «Добавлено: Моя трасса. Только в этой сессии», девятая карта и страница 2/2. Подмена callback вызовом из JavaScript не использовалась.
3. Импорт применён: `currentTrackId=my-mixed-track`. В BOT показано объяснение отсутствия подготовленного бота, применение отключено. В SOLO начался настоящий заезд с одним героем; без ввода герой столкнулся трижды и выбыл слева на 2036 ед / 10,6309 с. Это проверка работы импортированной геометрии и режима, не оценка её сложности.
4. Меню проверено при 1280×720 и 568×320: прежние восемь карточек, девятая ячейка импорта, вторая страница, стрелки по 44 и нижняя кнопка не перекрываются. [Компактный снимок](v543-json-menu-compact.png), [меню итогового архива](v543-json-menu-desktop.png). Override viewport снят.
5. В отдельной тестовой копии временно отсутствовал index: реальный HTTP404, видимая причина и повтор, `data-flip-state=null`, играбельной подмены нет. Затем вместо первой трассы сервер вернул HTML: показана ошибка `full-long.track.json: JSON, позиция 0`, игра по-прежнему не создана. После точного восстановления файла повтор вернул ready с восемью картами. [Снимок 404](v543-json-http404.png). Временный сервер остановлен; исходные ассеты/релиз не повреждались.
6. После перезагрузки страницы сессионная карта исчезла, исходный каталог снова содержит восемь карт.
7. На постоянном адресе загружена **распакованная копия итогового ZIP**. На Передумай бот-Мастер/Основной завершил за **34,85 с**, 0 ударов/замедлений, 3 обычных бонуса и полный финишный рывок 0,25 с. [DOM-диагностика настоящего забега](v543-browser-bot.json): 1116 активных измерений, максимум bot+diagnostics 11,8 мс, кадров >50 мс нет, автоматической паузы нет.

Ошибочные локальные файлы и поздние callbacks покрыты managed/HTML проверками; в настоящем браузере проверен успешный file chooser и ошибки сетевого каталога. Физический телефон, отдельные исторические stage-сборки и JavaScript-реализация этим выпуском не проверялись. Это конечная приёмка переноса, не новая калибровка ботов или плейтест удовольствия.
