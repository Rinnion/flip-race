# Мастерская 0.5.23: сводка выбранного прохождения

17 ноября 2026. Принято и выпущено. Ветка `experiment/workshop-analysis-0.5.17`, база cc016ad (0.5.22). Источник — прямой запрос пользователя: сводка темпа, допуска, серий сложных мест и переход к ним на карте; новая версия.

| RELEASE | 0.5.23, Web/HTTP/браузер, архивы/документация | Root | Принято |

WORKSHOP изменяется; CONTROL, TRACKFILE, SURFACE-RUN сохраняются, Core и поиск не затрагиваются. Сводка производная от выбранного replay и совместимого пакета матриц, новой копии результатов в JSON не требуется.

Решения Astra/high: критический темп <150 мс; низкий допуск при исходной доле безопасных клеток <7%, ровно 7% умеренно. Источник допуска — уникальные batch.targets, перекрывающиеся пары сохраняются как отдельные проверки. Сложные интервалы объединяются только при общей команде: темп [i−1,i], пара [i,i+1], одиночное [i,i]. Произвольная норма времени восстановления не вводится. Реализация Sol/high; root интегрирует и проверяет.

## Проверки и приёмка

- [109 Web-тестов](workshop-replay-summary-web.tap), включая 7 новых проверок модели сводки: границы темпа, низкий допуск, неизвестные данные, дедупликация матриц, транзитивное объединение, реальные/заданные интервалы и недостигнутые команды. ES-module syntax app.js прошёл.
- Независимое ревью Sol/high завершено без открытых замечаний. Уточнены подписи времени: реально достигнутые координаты/времена отделены от запланированных недостигнутых, промежуток по расписанию помечен «по ленте».
- Публикации .NET 8/10 без ошибок; по 30 HTTP smoke-запросов на финальных пакетах: [net8](workshop-summary-smoke-net8.json), [net10](workshop-summary-smoke-net10.json). Серверные алгоритмы/Core не изменены, прежний полный прогон 6533 не повторялся для производной Web-сводки.
- Браузер: «Полоса уловок», Основной без разгона, [0.5,0.6,0.7,2,2.1,4]: 3/5 критических интервалов (60%), минимум 100 мс, 2 серии, максимум 2 интервала/3 команды, 2 трудных места/5 уникальных команд. Промежуток 1300 мс. Без матриц допуск явно не рассчитан.
- Переход ко второй связке выделил команду №4 на схеме; панели парной/одиночной проверки остались закрыты, расчёт не запускался. Добавление [100,100.1] дало третье запланированное недостигнутое место, неизвестные X и отключённые переходы.
- «Передумай», [1.65,4.15,4.25]: 1/2 критических интервалов, одна связка №2–3. После batch — 2/2 готовые матрицы, минимум допуска 66% при исходных 23,84% (149/625), низких 0. Из карточки открывается точная матрица №2–3 из 625 клеток.
- Правка ленты, управление FastFlip и длина 7920→8000 скрыли прежнюю сводку. Восстановление сохранённого прохождения и undo геометрии вернули данные без batch-пересчёта. Ошибок консоли нет. [Скриншот](workshop-summary-0523.jpg).
- [Аудит пакетов](workshop-summary-packages.json): 52/58 файлов, по 46 сравнений ресурсов с исходниками, ZIP побайтово совпадает с публикацией/CRC, 39 исходных Core-файлов неизменны.
