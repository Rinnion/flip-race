## Ворота G1: что требуется до полных трасс

- [x] Прототип содержит 5–7 **осмысленных** действий, а не просто несколько камней на одной стороне. Для каждого действия понятно, что меняет его пропуск: безопасный путь, кольцо, столкновение или обход отрицательного.
- [x] Уход до камня и возврат после него проверены при фактической скорости. Новый перелёт нельзя начать до завершения предыдущих 0,8 с; ускорение/замедление не делает маршрут недостижимым.
- [x] Слишком ранний возврат сталкивается с видимым задним краем, своевременный получает кольцо и награду, поздний пропускает её. Можно остаться на безопасной стороне.
- [x] Две высоты камней и несколько высот колец совпадают с расчётом столкновений/касания.
- [x] Награда за положительное кольцо выдаётся только после успешно завершённого связанного манёвра; контакт с кольцом сам по себе ещё не награда. Столкновение отменяет текущую неподтверждённую награду, прежние сохраняются.
- [x] Отрицательное кольцо видно заранее, различимо контуром и символом и имеет проверяемый обход. Контакт даёт потерю 0,3 с, сохраняя управление.
- [x] Близкие одноимённые и противоположные эффекты полностью отрабатываются по описанной политике; одна пара «плюс/минус» даёт нулевое изменение времени.
- [x] После ошибки или замедления следующий удар не становится вынужденным.
- [x] Реальные заезды/тесты проверяют движение и пересечение финиша; надпись результата не служит единственным доказательством.
- [x] Есть успешные автоматические результаты и играбельная браузерная демонстрация серии. Автоматические и браузерные свидетельства первого этапа получены; ссылки ниже.

## Контрольные времена

Относительно той же геометрии без эффектов и ошибок, после **полного** отыгрыша всех полученных эффектов:

| Сценарий | Разница | Полная трасса при baseline 36 с |
|---|---:|---:|
| Одно положительное | −0,3 с | 35,7 с |
| Одно отрицательное | +0,3 с | 36,3 с |
| Одно положительное + одно отрицательное | 0 с | 36,0 с |
| Два положительных + столкновение | −0,1 с | 35,9 с |
| Шесть положительных, отрицательные обойдены | −1,8 с | 34,2 с |
| Шесть положительных + два отрицательных, без столкновений | −1,2 с | 34,8 с |

Произвольный тест с эффектом у самого финиша должен учитывать лишь фактически отработанную часть. Полные подготовленные трассы обязаны оставлять достаточно места, чтобы **все** полученные эффекты завершились до финиша; хвост очереди не должен незаметно обрезаться.

## Стартовый независимый аудит v2

Read-only проверка обнаружила ожидаемое ограничение v2, существенное для плотных v3-серий: следующая награда перезаписывает активный `BoostRemaining` и обнуляет `BoostElapsed`. Теряется как остаток предыдущего эффекта, так и запись уже отработанной части, используемая при расчёте времени финиша.

Воспроизведение в памяти, без изменения runtime: искусственная трасса длиной 2200, без препятствий; кольца `X=100/110, Y=226, Radius=6, ClearX=101/111`. Оба игрока едут без переворотов. Результат v2: две награды, только один завершённый эффект, записанный финиш `9,7` с при физическом пересечении на `9,684848484844922` с. Если сохранить оба полных эффекта, требуемый результат — `9,4` с. Это контрпример старого допущения, **не** проверка готовности v3 и не ошибка подготовленных v2-трасс, где эффекты разнесены.

SHA-256 прочитанного v2 Core: `df5bdd194d6d1077a6f849c99ee8fb971a41c30f7c60dd5f66e73c066eee856f`. Этот результат относится к снимку v2 до реализации v3; исправление покрыто текущими FIFO-тестами.

Для v3 переданы обязательные проверки: сохранение активной отработанной части и FIFO-хвоста, стабильный порядок равновременных событий, приоритет столкновения над связанной наградой, границы after-ring, две зоны одного камня, пустая очередь перед финишем. Старые проверки восстановления с делением расстояния на базовую скорость не доказывают восстановимость при slow/boost; нужны проверки фактического движения.
