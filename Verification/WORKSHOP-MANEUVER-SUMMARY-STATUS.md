# Мастерская 0.5.24: статистика целых матриц

17 ноября 2026. Реализовано; программные проверки пройдены. Визуальная приёмка ограничена настройками среды. Ветка `experiment/workshop-analysis-0.5.17`, база 191b42c (0.5.23).

Прямой запрос пользователя: бот задаёт возможный референс, сложность манёвра выражается всей матрицей; нужна статистика оценок и промежутков, трудные целые манёвры и отдельная полнота. Пользователь подтвердил единицы промежутков — миллисекунды, от самого позднего безопасного нажатия предыдущего манёвра до самого раннего безопасного следующего.

WORKSHOP изменяется; CONTROL/TRACKFILE/SURFACE-RUN сохраняются. Решение Astra/high, реализация Sol/high. Готовая матрица с 0 безопасных клеток имеет оценку 0, но неизвестное безопасное окно. Pending/unsupported не дают ложный ноль. Медиана чётного набора — среднее двух средних оценок после преобразования. Пары длинной цепочки остаются отдельными наблюдениями; общие команды отмечаются. Промежутки — по локальным безопасным альтернативам, без утверждения о гарантированном отдыхе.

## Проверки и результаты

- [111 Web-тестов](workshop-maneuver-summary-web.tap), включая 9 тестов новых правил: калибровка до медианы, равный вес матриц, готовый ноль/неизвестность, настоящие безопасные времена, знаковые промежутки, запрет соединять окна через неизвестный манёвр, отдельные пары и граница 7%.
- Синтаксис `app.js` и `git diff --check` пройдены. Независимый review Sol/high: замечаний нет.
- Публикации .NET 8 и .NET 10. По 30 HTTP smoke-запросов: [net8](workshop-maneuver-smoke-net8.json), [net10](workshop-maneuver-smoke-net10.json).
- Реальный расчёт матриц и восстановление сводки из JSON на обеих сборках: [net8](workshop-maneuver-http-net8.json), [net10](workshop-maneuver-http-net10.json). Полный Chosen-референс «Передумай», distance, без разгона: 16 готовых матриц из 17; допуск min 54,71698%, max 100%, median 83,32075%; 15 известных промежутков из 16, min −431,818 мс, max 2673,551 мс, median 867,153 мс; 3 перекрытия, 0 трудных готовых матриц.
- Искусственная цепочка `[0.05, 0.1, 0.15]`: две отдельные парные матрицы, 3/625 и 91/625 безопасных клеток. Только первая входит в трудные места; пары не сливаются в группу из трёх команд.
- [Аудит пакетов](workshop-maneuver-packages.json): все 39 Core-файлов совпали с базой, по 46 сравнений ресурсов публикации; ZIP проверены по составу, CRC и побайтовому содержимому.

## Сборка и ограничения приёмки

[Открыть мастерскую 0.5.24](http://127.0.0.1:4244/). Постоянный net8-процесс PID 29100. Временный net10-процесс PID 16952 на 4245 завершён после сверки командной строки; прежние мастерские оставлены.

Архивы: `Releases/track-workshop-0.5.24-experiment-win-x64.zip` (52 файла), `Releases/track-workshop-0.5.24-experiment-server.zip` (58 файлов). Нормативная статья обновлена в `../flip-race/docs/authoring/workshop.md`; отдельный репозиторий, прежние изменения сохранены.

Браузерная приёмка 0.5.24 не выполнена: попытка открыть локальную сборку через CUA вернула `Local browser use is disabled in Work settings`. Снимка новой версии нет. Автоматические и интеграционные проверки не выдаются за визуальную проверку. Остаётся проверить внешний вид и переходы в браузере при доступном инструменте; реализация и архивы доступны для пользовательской пробы.

Физика, поиск, сетка ±600 мс, управление и JSON-схема не менялись. Новые числовые агрегаты вычисляются из совместимых сохранённых матриц; повторный расчёт не требуется. Отдельный темп референса сохранён. Это допуск локальных альтернатив, не вероятность успеха человека и не доказательство совместимости крайних альтернатив соседних матриц.
