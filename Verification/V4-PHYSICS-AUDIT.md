# V4: независимый аудит физики

Проверено 16 октября 2026 года. **PASS: 7 836 проверок**, блокирующих замечаний в V4-01/02 не найдено. Это отдельный численный harness над фактическим C# Core: 954 проверки базовой гравитации, 6 750 — воздушного повтора, 132 — отложенной награды после камня. Он не запускает Unity и не подменяет браузерную проверку или плейтест.

Исходник проверки сохранён в [v4-independent-physics.cs.txt](v4-independent-physics.cs.txt), результат — [v4-independent-physics.txt](v4-independent-physics.txt). Runtime этим аудитом не изменялся.

## Что проверялось

| Область | Независимый ориентир и результат |
|---|---|
| Базовая гравитация | Обе поверхности, положения и скорости из `y=y0+v0·t+a·t²/2`, `v=v0+a·t`. Путь центра 212 при ускорении 662,5 даёт посадку на 0,8 с. После посадки поперечная скорость 0; горизонтальная дистанция продолжает расти |
| Повтор в воздухе | Для первого плеча τ=0,05 / 0,2 / 0,4 / 0,55 / √0,32 / 0,6 / 0,75 с второе нажатие сохраняет скорость и возраст полёта. Третье отклоняется. Возврат без противоположного касания наступает в `τ·(2+√2)`, а не по прежнему cutoff 0,8 с |
| Неверная поверхность | При τ>√0,32 первое касание другой поверхности в `2τ−√(2τ²−424/662,5)` обнуляет скорость, но не возвращает заряд. Правильная посадка наступает ещё через 0,8 с. Проверены обе стороны |
| Кольцо | Вырождение a=0, почти нулевое a, касательный двойной корень, четыре корня, контакт в начале/конце интервала, промах и проход на 0,0001 единицы от касания. Скорости 110/220/330, оба знака ускорения; ближайший пересекающий корень отдельно сверен бисекцией прямого геометрического расстояния на известном интервале |
| Камень | Аналитический горизонтальный контакт на 0,3 с: x=66, центр y=196,1875, vy=−198,75. Удар замораживает x/y/vy/притяжение; продолжение приводит к нормальной посадке |
| Награды и FIFO | Свободное кольцо подтверждается немедленно; совпавший удар не отменяет свободную награду, связанная отменяется. ++, −−, +−, −+, несколько подряд: фактическое время финиша, полная очередь и отсутствие двойного начисления |
| Кольцо после камня | Настоящий контакт до конца полёта остаётся pending; чистый возврат на исходный пол подтверждает награду в реальный момент посадки. Позднее касание неверного потолка её ещё не подтверждает. Ранний возврат сначала собирает кольцо, затем задевает заднюю часть связанного камня: награда отменена. Реальные финиши 9,7 / 10,5 с |
| Восстановление и сброс | Потраченный повтор, инерция и активный эффект сохраняются в заморозке. 0/NaN/Infinity не продвигают состояние. Реванш ждёт двоих, сбрасывает движение/эффекты и сохраняет вариант/героев |

Все сценарии движения повторены с шагами **1/30, 1/60, 1/144, 0,317, 2,5 и 100 с**. Большие шаги относятся к прямой проверке Core; браузер может отдельно ставить игру на паузу после длинного кадра.

Камни сохраняют модель расширенного прямоугольника прежней версии; это не контакт круга с закруглёнными углами. Кольца используют сумму физических радиусов и непрерывную параболическую траекторию. Разбиение на события поверхности, разворота скорости, кольца, столкновения, FIFO и финиша прочитано отдельно от тестов.

## Численная оговорка

У математически точного касательного контакта противоположной поверхности при τ=√0,32 и шаге 1/30 с округление двойного квадратного корня сдвигает событие примерно на 3,1e−8 с. В точный момент вершины измерено vy=−2,07054e−5 вместо 0. Направление, заряд, возврат и конечная посадка правильные. Для этого единственного порогового случая допуск координаты/скорости — 1e−4; для остальных воздушных траекторий — 2e−7. Это неблокирующая численная погрешность, не изменение механики.

## Повторный запуск

PowerShell 7, из корня Unity-проекта, в новом процессе:

```powershell
$trialProbe = Join-Path $env:TEMP ('flip-v4-audit-' + [guid]::NewGuid())
New-Item -ItemType Directory -Path $trialProbe | Out-Null
Copy-Item -LiteralPath Verification/v4-independent-physics.cs.txt -Destination (Join-Path $trialProbe 'Probe.cs')
$sourceFiles = @(Get-ChildItem -LiteralPath Assets/Scripts/Core -Filter '*.cs' | ForEach-Object FullName)
Add-Type -Path ($sourceFiles + (Join-Path $trialProbe 'Probe.cs'))
[V4Independent]::Run()
```

Геометрические маршруты проверены отдельно ниже; браузерные режимы/пауза, качество подсказок и физические телефоны имеют отдельные свидетельства. Автоматический PASS не утверждает, что игроки предпочли новое управление.

## Независимая проверка V4-03 после фиксации геометрии

**PASS: 4 321 проверка в 70 завершённых играх.** Отдельный [исходник](v4-independent-geometry.cs.txt) и [stdout](v4-independent-geometry.txt). Это дополнение к 7 836 проверкам физики, а не повторный подсчёт тех же тестов.

Планировщик этого harness ограничивает каждый шаг оставшейся дистанцией до ближайшего ввода любого игрока, делённой на максимальную скорость 330. Поэтому неожиданное начало свободного ускорения не перескакивает ввод. Он не использует клонирование игры или алгоритм планировщика TrackProofV4.

- Во всех трёх вариантах один общий безопасный маршрут: **20,0 с / 0 колец / 0 столкновений**, без воздушных повторов.
- В варианте C полный сбор: **18,8 с / 4+ / 0− / 0 столкновений**, два намеренных воздушных повтора.
- Поспешный возврат: **19,4 с / 3+ / 1− / 0 столкновений**; выдержанный идеальный путь собирает положительное и избегает ловушки. Слишком поздний возврат: **19,1 с / 3+ / 0− / 0 столкновений**.
- Соперники проходили разные маршруты одновременно; их назначения менялись местами. Победитель совпадает с фактическим временем. Все 16 пар героев на одинаковом маршруте дают точную ничью.
- Проверены шаги 1/30, 1/60, 1/144, 0,317, 2,5 и 100 с. В каждом финише заработанные эффекты полностью отработаны, активный эффект и очередь пусты.
- Полная группа ловушки от первого возможного контакта с камнем до дальней границы положительного кольца занимает **274 мировые единицы**. Минимальный обзор `CorridorArtwork` — 1080 единиц; геометрия помещается целиком до входа. Фактическую читаемость проверяет браузерный отчёт.

Источник `TracksV4.cs`: SHA-256 `da3242d2d9adee589cf9cf52c4842699d0693f8dfd2d7feccb4cc06015888ddb`. Harness: `4fe2a8448d02dd72715c34c93cf99ced04f18c49d1dbd39912c3093abdc50a8f`. Для повторного запуска в команде выше заменить имя файла на `v4-independent-geometry.cs.txt` и класс на `V4GeometryIndependent`.

Основной геометрический proof отдельно сообщил **17 091 проверку**, включая 244 состояния столкновения: 47 Linear, 62 Gravity, 55 GravityAirFlip safe и 80 ideal. Его поиск выхода проверен чтением: завершает остаток реальной заморозки, ждёт реакцию 150 мс, использует только доступные нажатия и требует фактически пройти следующий камень. Эти 244 случая не входят в 70 независимых игр; это выборка восстановимости, а не доказательство для всех возможных действий игрока.
