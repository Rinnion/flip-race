### Полная конечная выборка recovery

Каждое действие каждого safe/full/trap маршрута сдвинуто отдельно на −800/−640/−400/−240/−160/−80/+80/+160/+240/+400/+640/+800 мс. Все prefixes заново исполнены через `Press`/`Advance` на R7. После первого столкновения исходный маршрут прекращается; управляющий поиск начинается после оставшегося штрафа и ещё **150 мс реакции**. Успех требует фактического достижения `next unionRight + radius + 1` без второго удара, включая обе части прохода. Последние случаи без следующего препятствия доходят до ленты.

[Полный JSONL R7](rhythm-r7-recovery-20261019-205957.jsonl) сохраняет каждый результат, состояние, эффекты, target и действия. Предыдущий JSONL R6 предоставляет только предложение действий, которое повторно проверяется на новом настоящем prefix и новой геометрии. Старые состояния и verdict не копируются; инъекций состояния нет. Меньшее число assertions R7 связано с отсутствием повторного поиска уже известных успешных действий, **не с уменьшением выборки**.

## Проба человеком — отдельно от автоматизации

Для 4.6.0-trial сначала выберите **Быстрый флип** и практику: пройдите обычный низкий порог, затем попробуйте быстрый возврат на ту же стену. После этого пройдите безопасный путь на Каскаде, Плотном потоке и Волнах. Только затем добавляйте посадки, цепочки бонусов и точную финишную цель. Повторите в обеих экранных половинах.

Отметьте, успеваете ли различать обе части прохода до решения, где теряется ритм или устаёт рука, видны ли передышки, и получается ли после одного удара восстановиться без заранее известного расписания. Сравните с Основным профилем. Это человеческая оценка, не уже выполненный PASS. **Физический телефон и настоящий multitouch не проверены**; браузерный viewport не заменяет их.

На каждом стыке подтверждены: настоящая `Wall` нужной стороны, VY=0, отсутствие полёта, восстановленный заряд, скорость 220, пустые active/queue/связанные ожидания, полностью отработанные начисленные эффекты. Вход с потолка приготовлен настоящими нажатиями, а не изменением полей. Геометрия обеих частей с радиусом полностью очищена до границы; события следующего модуля не начинаются раньше его входа. ID каждого instance и все `ObstacleId` перенесены в отдельное пространство имён.

| Тип | Исходная длина | Compact длина | Консервативный конец обычной работы | Запас compact |
|---|---:|---:|---:|---:|
| gate | 300 | 270 | 0 | 270 |
| free | 380 | 350 | 334 | 16 |
| free-high | 380 | 355 | 350 | 5 |
| before | 500 | 480 | 457 | 23 |
| after | 600 | 580 | 560 | 20 |
| chain | 700 | 690 | 674 | 16 |
| pad | 520 | 460 | 446 | 14 |
| large | 700 | 600 | 524 | 76 |

Таблица относится только к двум указанным ранним экспортам. Она не описывает окончательный R5: before был расширен через R2/end520 до исправленного before400/end590, large сокращён до 580. Их отдельные результаты и причины изменений приведены выше; исторические captures не подменены новыми числами.

Граница работы рассчитана независимо по последнему возможному контакту/начислению; linked clear использует реальный `unionRight + R + epsilon`, посадка — правый край окна. Каждый импульс получает консервативные 198 единиц движения, даже если он отрицательный. Для модулей перебраны их собственные subsets (не 2 048, поскольку в них не 11 наград). Минимальный запас 5 единиц не является допуском ошибки игрока: это запас верхней оценки отработки эффектов.

Stdout: [исходные модули](rhythm-modules-independent.txt), [compact](rhythm-modules-compact-independent.txt). Core `AA91B969…` / helper `BB1A5F4F…` не менялись; точные SHA включены в stdout и повторно сверены после исполнения.

Это **не** полный аудит трасс. Подтверждён контракт чистого входа/выхода, но не восстановление после удара, удобство игроку, отсутствие глобального обхода или плотность курса. Добавление отрицательной награды может нарушить условие пустых эффектов на следующем стыке: её маршрут и общий остаток работы проверяются отдельно.

## Объём проверок и оставшиеся gates

Независимый [FullCourses.cs](../Tools/RhythmAudit/FullCourses.cs) исполнил проверки R7 на замороженном export и сверил его с runtime. `All`, Core и трассы аудитором не изменялись. Активация каталога и сборка выполняются после этого CPU gate; браузер и пакет относятся к RHYTHM-05.

| Проверка | Критерий | Статус |
|---|---|---|
| Бюджет и ID | Длина 7920; 9 обычных положительных, 2 отрицательные, 1 finish; 3 посадки, before/after; уникальные ID и настоящие ссылки, обе части ворот | R7 PASS, точные SHA и capture выше |
| Общий хвост | Все **2 048 subsets** одиннадцати обычных наград, release по circle/landing/real unionRight; каждый upper envelope заканчивается до X7876; последние 44 единицы без других событий | R7 PASS, все 2 048 subsets |
| Физический финиш | Для каждого профиля safe/full/trap, шесть dt до 100 с; фактические Distance/Elapsed/FinishTime, полностью обслуженные ledgers и пустые эффекты | R7 PASS, шесть dt |
| Окна | По одному действию ±60 мс для safe и ±25 мс для full; часы учитывают реальные эффекты, не X/220 | R7 PASS в указанном конечном scope |
| Полезность и сокращение | Удаление каждого одиночного действия и соседней пары; сравнение реального clean outcome, принятых и проигнорированных действий; найденный более простой путь сообщается | R7 PASS в указанном конечном scope |
| Ритм | Реальные времена входа/выхода каждой группы, принятые действия, интервалы, начальный/финальный простой и межгрупповые паузы отдельно для safe/full обоих профилей | R7 PASS, реальные group/action clocks |
| Простые обходы | Пол/потолок, настоящее приготовление, feedback к центру, ограниченный набор частот/фаз; контрпример-поиск, не доказательство глобального минимума | R7 PASS в указанном конечном scope |
| Ошибки и замедление | Реальные hit-состояния, остаток recovery +150 мс, достижение следующего полного unionRight+R+1; purposeful trap и независимость игроков | R7 PASS: все 3 844 actual states, 0 no-found; конечные окна и ограничения указаны выше |
| Полный браузер и пакет | Новые трассы, оба профиля/слота, мобильное меню, сохранение настроек, версия и запуск из ZIP | Последующий RHYTHM-05 PASS в [отдельном браузерном scope](FLIP460-BROWSER.md); CPU gate не заменяет браузер |

Результат удаления действия не обязан быть ударом: потеря выбранной награды или подходящей дальнейшей опоры также меняет манёвр. Если более короткий путь сохраняет весь заявленный clean outcome, он не объявляется «полезным вводом» ради счётчика. Диапазоны количества действий — дизайн-цели, а не основание менять физику или скрывать найденное сокращение.

## Воспроизведение

Из корня Unity-проекта:

```powershell
pwsh -NoProfile -File Tools/RhythmAudit/Run.ps1 -Scope modules
pwsh -NoProfile -File Tools/RhythmAudit/Run.ps1 -Scope modules-compact
pwsh -NoProfile -File Tools/RhythmAudit/Run.ps1 -Scope courses-final -CourseFile rhythm-r7-routes.json
pwsh -NoProfile -File Tools/RhythmAudit/Run.ps1 -Scope courses-duels -CourseFile rhythm-r7-routes.json
pwsh -NoProfile -File Tools/RhythmAudit/Run.ps1 -Scope courses-bypass -CourseFile rhythm-r7-routes.json
pwsh -NoProfile -File Tools/RhythmAudit/Run.ps1 -Scope courses-recovery-expanded -CourseFile rhythm-r7-routes.json -RecoverySeedFile rhythm-r6-recovery-20261019-204609.jsonl
```

`Capture.ps1` с тем же scope дополнительно хеширует соответствующий JSON до/после исполнения. Новые результаты сохранять под новым именем; существующие snapshots и отчёты не перезаписывать. Компиляция helpers полных курсов сама по себе не означает PASS тестов.
