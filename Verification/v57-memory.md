# Память прогнозов четырёх ботов

8 ноября 2026. Исправление для Unity 5.7.0-trial. Первая сборка прошла managed-проверки, но реальный WebGL завершился `abort("OOM")` при первых совместных прогнозах четырёх ботов на Проявлении. Лимит WebGL 256 МиБ сохранён.

## Причина и исправление

Пробные манёвры создавали много временных массивов корней и полных снимков мира внутри одного кадра. В WebGL сборка мусора выполняется между кадрами, поэтому малый объём живых данных после GC не исключал исчерпания памяти в одном вызове. [Описание памяти Unity Web](https://docs.unity.com/en-us/engine/6000.0/manual/platform-specific/webgl/develop/memory).

`ContinuousMotion` использует ограниченные стековые буферы для коэффициентов, корней и границ. Арифметика, сравнение чисел и порядок поиска сохранены. `RaceSnapshot.ForecastWorkspace` повторно использует два независимых снимка внутри одного планирования. Откат меняет рабочий снимок и контрольную точку местами, новый кандидат восстанавливается из исходного мира. Личные наборы, очереди, эффекты и общий скрытый мир копируются без ссылок на живую гонку. Публичный `Clone` сохраняет прежний контракт. Число кандидатов, бюджеты, случайность и игровые решения не менялись.

## Независимое воспроизведение

Фиксированы seed `0x17f08c21`, Проявление, Основное, камера последнего, стандартный разгон и четыре уровня Любитель / Новичок / Сильный / Мастер. Шаг 1/30 с, наблюдение выделений до 18,033 с симуляции.

[Исходный замер](v57-memory-before.json), [повтор](v57-memory-after.json). Измерения выполнены отдельным диагностическим инструментом в `.scratch-v57-core-probe` и `.scratch-v57-memory-after`. Они не являются замером кадров WebGL. Полная запись обоих заездов до финиша совпала побайтно: SHA-256 `44ECCB42867D23ADB046C8426C400190E1B44D11599EE1B3185D31D9F1E3DDF7`, время 34,364 с, 96 решений и 98 образцов нажатий.

Постоянная воспроизводимая регрессия включена в [PartyBotsCheck](../Tools/PartyBotsCheck/README.md): `--allocation`, предельный шаг 0,3 с и порог 32 МиБ за вызов для фиксированного сценария. Дополнительно 833 проверки сравнивают восстановление буферов с публичным снимком, включая null скрытого мира, скаляры, очереди и общие ссылки внутри копии. Полный набор Core содержит 1611 утверждений.

После последней правки повторно прошли 23 прежних сценария против неизменённой базы 5.6.0, 600 случаев общей физики, скрытые прогнозы, подготовленные импорты, все 28 составов, полный PartyUi и исторический эталон 40 228 снимков / 1 448 208 полей.
