## Контракт CONTROL-01 для независимой проверки

Метка — узкая часть реальной обращённой в коридор грани камня. Касание определяется пересечением плоскости и координатой центра вдоль грани на всём шаге. Большой круг прежнего instant не заменяет этот тест.

Правильная посадка имеет локальный приоритет над одновременным ударом о **тот же** камень. Ранее произошедший боковой удар не отменяется. При гравитации к камню появляется `Support=Stone` с конкретным ID и стороной; при гравитации от камня скорость в грань гасится, но устойчивой опоры и нового заряда нет. При движении по уже разрешённой опоре безопасна вся грань. Новое приземление мимо метки и другие грани штрафуются.

Успех даёт один мгновенный boost каждому игроку за заезд. После расходования бонуса точная повторная посадка всё ещё безопасна; постоянная площадка остаётся видимой. Успех не должен помечать весь камень как навсегда безвредный.

## Главные риски контакта и опоры

- После схода по фактическому trailing edge центр ещё может лежать внутри прежнего расширенного на R прямоугольника. Нужен локальный контроль выхода, иначе возникает нулевой по времени повторный удар. Договорённость об exact edge фиксируется в реализации/аудите; это не общая неуязвимость камня.
- Старт с плоскости тоже даёт t=0 в inclusive collision-band. Уход от разрешённой грани не должен штрафоваться; возврат вне метки должен снова считаться неправильным.
- Горизонтальное движение по опоре расходует boost/slow, пересекает конец эффекта и край камня в правильном порядке. Recovery/пауза замораживают остатки и опору.
- Положение на камне не равно крайнему Y=0/1. Выбор направления старта должен использовать SupportSide, а подтверждение linked-after должно учитывать настоящую устойчивую посадку.
- Корректная посадка одновременно с другим препятствием не отменяет чужой удар; свободный instant одновременно с неправильным ударом сохраняет обе реакции.
- Награда после приземления одноразовая, безопасность самой метки сохраняется; поля опоры сбрасываются при реванше и не разделяются между игроками.

## Следующие режимы и геометрия

CONTROL-02 проверяет сохранение VY на воздушной смене гравитации, линейный модуль **265** и реальное время по оставшемуся пути. Прыжковый режим сохраняет притяжение к прежней стороне при первом тапе и меняет только знак на втором. Его высота/время задаются отдельно; старые 140 при a1000 дают лишь 9,8 высоты. Unlimited реагирует на каждое отдельное нажатие без произвольного лимита/кулдауна и без накопления импульса.

CONTROL-02 зафиксировал a1000/u70 для первого и unlimited, a662,5/u400 для обычного прыжка, |VY|=265 для linear. Эти параметры численно подтверждены [независимым аудитом](CONTROL-MODES-AUDIT.md); предпочтение управления человеком ещё не установлено. Ограниченный заряд возвращается только при допустимой устойчивой посадке. Сход с края не выдаёт новый прыжок с отсутствующей опоры.

У каждого режима нужен маршрут без обязательных наград и маршрут всех положительных без отрицательных. У гибрида второй тап может быть необходим для смены стены; старое требование safe без air-repeat к нему не применяется. Для unlimited отдельный участок должен требовать осмысленной смены высоты, а не только удержания в пустом центре.

Сохранить исправления колец 4.0.1, приоритет instant/остатки/обычную очередь 4.1.0, равных героев, готовность обоих и быстрый реванш. Новая поставка не доказывает физический мультитач или предпочтение управления до соответствующего плейтеста.
