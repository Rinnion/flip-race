## Независимые численные ориентиры

Вертикальный путь между стенами — 212. Для начальной скорости от опоры u и ускорения в ту же сторону a: `q(t)=ut+at²/2`, `T=2D/(u+√(u²+2aD))`. Для обычного прыжка: `q(t)=ut−at²/2` до воздушной смены гравитации. При каждом воздушном тапе oracle продолжает движение из фактических координаты и скорости.

| Режим | Параметры / аналитическое ожидание |
|---|---|
| Меньше толчок | a=1000, u=70; полный перелёт **0,5849045732 с**, скорость перед стеной **654,9045732**. Мгновенный обратный тап оставляет минимальный подскок **2,45** |
| Линейный разворот | Модуль VY=**265**, полный перелёт **0,8 с**; разворот после 0,123 с возвращает на исходную стену ещё за 0,123 с |
| Прыжок + смена гравитации | a=662,5, u=400; вершина через **0,6037735849 с**, высота **120,7547169811**, возврат без второго тапа через **1,2075471698 с** |
| Неограниченные флипы | a=1000, u=70 при уходе с опоры; дальнейшие нажатия меняют только знак ускорения, без повторного u и лимита количества |
| Линейный старт с камня H48 | До другой стены **164/265=0,6188679245 с**; сход до прежней стены **48/265=0,1811320755 с** |

Для обычных сравнений использован допуск 3e−7. Значения выше служат независимым ориентиром; тесты вычисляют их из формул, а не вызывают production helper. Важное ограничение геометрии Jump: от пола минимальный центр Y=105,245283, поэтому противоположный потолочный камень H92 с плоскостью центра Y=106 слегка перекрывает вершину дуги. Геометрия должна проверять реальные расширенные границы, не считать такой камень автоматически безопасным.

## Проверенные переходы

- Moderate и unlimited: аналитические Y/VY до стены, ранний воздушный возврат, поздний разворот с инерционным касанием противоположной стены. Неправильная относительно гравитации стена гасит VY, но не даёт опору/новый ограниченный заряд и не добавляет толчок.
- LinearAirFlip: при воздушном нажатии меняется знак VY, координата непрерывна; следующий ограниченный повтор отклоняется. Время определяется оставшимся путём.
- Jump: первый тап направляет VY от опоры, сохраняя гравитацию к ней; дуга достигает аналитической вершины и возвращается. Второй тап меняет только гравитацию. Поздний второй тап сохраняет инерцию: герой может сначала коснуться старой стены без опоры/заряда, затем уйти от неё под действием гравитации.
- Unlimited: **64** отдельных воздушных нажатия на каждом зеркальном прогоне совпадают с независимым поучастковым расчётом. Ещё два нажатия подряд без продвижения времени принимаются и восстанавливают исходный знак гравитации, не меняя VY.
- Все четыре режима: реальная узкая landing на верхний/нижний камень даёт опору и один бонус. Сход происходит на фактическом крае, без ложного удара; linear начинает падение со скоростью 265, остальные — с VY=0 без толчка.
- Старт с камня использует его настоящую плоскость. Jump сначала выполняет обычный прыжок и только вторым тапом меняет гравитацию; все режимы достигают другой стены по фактическому оставшемуся расстоянию.
- Нажатие только верхнего игрока не меняет нижнего. Разные вертикальные маршруты на свободном участке дают точную ничью по фактическому горизонтальному времени 20 с. Реванш ждёт двух готовых, сохраняет режим/профиль/героев, сбрасывает время, движение и поддержку, возвращает стартовый заряд.

Source review проверил применение нулевого ускорения LinearAirFlip в движении, контактах и горизонтах событий. Старый Linear остаётся отдельным режимом. Landing сохраняет локальный приоритет и правила опоры, рассмотренные в CONTROL-01; новых блокирующих замечаний нет.

Отдельный engine-прогон: **CONTROL 19 сценариев / 2 165 утверждений**, прежние V1/V2/V3/V4/TUNE и JS differential **40 228 snapshots / 1 448 208 полей** PASS. Эти числа не входят в независимые 10 524.

## Воспроизведение

PowerShell 7, из корня Unity-проекта, новый процесс. Для точного повторения использовать указанный снимок Core; поздние изменения фиксировать как отдельный прогон. Unity не запускается.

```powershell
$auditDir = Join-Path (Split-Path $PWD -Parent) ('.tmp-control-modes-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $auditDir | Out-Null
Get-ChildItem -LiteralPath ./Assets/Scripts/Core -Filter '*.cs' |
    Copy-Item -Destination $auditDir
Copy-Item -LiteralPath ./Verification/control-modes-independent.cs.txt -Destination (Join-Path $auditDir 'ModesProbe.cs')
$auditSources = @(Get-ChildItem -LiteralPath $auditDir -Filter '*.cs' | ForEach-Object FullName)
Add-Type -Path $auditSources
[ControlModesIndependent]::Run()
```
