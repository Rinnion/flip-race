## Принятые уточнения

Только совместимые награды выбранного чистого ориентира входят в намерения и B; остальные физически существуют, но не считаются пропущенными целями. Все логические препятствия, включая скрытые, входят в C. Бот знает карту заранее; добавлять отдельную видимость намерений не требуется. Невыполнимое столкновение с ещё нетвёрдым камнем не подделывается. Возможное необходимое исправление: прогноз должен независимо копировать текущие clocks скрытых камней и настройку предупреждения.

Для скрытых карт прогноз копирует всех текущих участников и их общее состояние. Другие участники продолжают обычную физику без новых Press, чтобы уже существующее тело человека корректно откладывало активацию. Stable ID сохраняются; Constant-выбывание исключается только из прогноза, как раньше. Неизвестный будущий ввод человека остаётся ограничением. Для прежних пяти карт сохранён старый персональный прогноз.

API согласован: BotReferenceRoutes.Get/Supports, immutable BotReferenceRoute.Inputs/RewardIds/BonusGain; StochasticTrackMap.SupportsTrack — лёгкая проверка8ID. Подготовлены5 чистых ориентиров: Intercepts Chosen8/Fast10 обычных наград, Manifestation6 обоими профилями, Rethink3; каждый также включает полный финиш. Дополнительные локальные пробы завершены, глобальный максимум не доказывался.
