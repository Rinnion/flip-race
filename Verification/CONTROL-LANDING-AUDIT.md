# CONTROL-01: независимый аудит посадки и опоры

Проверено 16 октября 2026 года на frozen Core первого gate. **PASS: 4 812 утверждений / 216 игровых прогонов.** Блокеров для CONTROL-02 не найдено. Это численный аудит посадки на существующем GravityAirFlip; новые четыре режима, браузер и будущая геометрия ещё не проверены этим результатом. Состояние этапов — [CONTROL-TASKS](CONTROL-TASKS.md).

Исходник — [control-landing-independent.cs.txt](control-landing-independent.cs.txt), результат — [control-landing-independent.txt](control-landing-independent.txt). Harness использует реальные готовность, `Press` и `Advance`: состояние посадки, опоры и награда не подставляются вручную. Проверены обе стороны коридора, оба игрока, камни высотой 48/92/120 и шаги **1/30, 1/60, 1/144, 0,317, 2,5 и 100 с**.

## Независимые ожидания и результаты

Для текущей базовой гравитации a=662,5, радиуса 14 и высоты коридора 240 плоскость центра на нижнем камне высотой 48 — y=178, на верхнем — y=62. От противоположной стены до этой плоскости: `t=√(328/a)=0,7036294050 с`, скорость перед контактом по модулю `a·t=466,1544808323`. После схода с фактического края до прежней стены остаётся 48: `t=√(96/a)=0,3806647611 с`.

| Случай | Проверенный результат |
|---|---|
| Точная посадка | Центр пересекает настоящую грань внутри узкой метки; VY гасится, появляются Stone/ID/сторона, возвращается заряд, выдаётся один instant |
| Границы метки | Оба точных конца включены; выход на 1e−6 даёт удар. Поля Y/Radius=999 у landing не превращают метку в круг |
| Движение по грани | Вся уже достигнутая опора безопасна за пределами узкой метки; прохождение другой метки по опоре не выдаёт бонус |
| Старт и повторная посадка | Старт непрерывен, без t=0 удара. Точный возврат безопасен без второй награды; возврат мимо метки штрафуется |
| Сход с края | Опора заканчивается при X=реальный trailing edge, VY=0 без автоматического толчка; дальнейшее падение аналитическое, расширенный collision slab не создаёт ложный удар |
| Касательный контакт | При обращённой от камня гравитации касание вершиной параболы безопасно и даёт бонус, но не опору/заряд. Дальше действует только гравитация |
| Чужой удар в тот же момент | Правильная посадка на A и боковой удар B сохраняются одновременно: опора/instant A, recovery B; движение и остаток эффекта заморожены на recovery |
| Более ранний боковой удар | Последующая близость метки не превращает удар в правильную посадку |
| Эффект до плоскости | Положительный/отрицательный эффект заканчивается в полёте; X контакта совпадает с независимым суммированием участков скорости |
| Эффект в момент посадки | Landing прерывает действующий slow с сохранением обслуженной части и остатка либо продлевает действующий positive; все импульсы учитываются ровно один раз |
| Независимость игроков | Нажатие верхнего игрока снимает только его опору; нижний продолжает движение по грани |
| Фактический финиш | Дистанция достигает 2200, реальное elapsed и FinishTime совпадают: 9,7 с за один boost, 10,2 с при нём и одном ударе, 9,4 с за два boost, 10,0 с за slow+boost |

Обычный допуск численных сравнений — 3e−7. Для касательной отдельно допущены 2e−5 по X и 2e−4 по VY: двойной корень усиливает машинное округление, а после раннего на несколько наносекунд контакта начинается boost. Допуск не расширяет проверяемые границы метки; случаи ±1e−6 проверены отдельно обычным пересечением. В обоих зеркальных касаниях проверены точная грань, отсутствие опоры/заряда, одноразовая награда и отсутствие повторного нулевого события.

## Review и исправления до freeze

Независимый review обнаружил два дефекта промежуточного кода: при старте с нижнего камня `FlipTo` расходился с Gravity; одновременный чужой удар откладывал правильную посадку до конца recovery. Engine исправил оба до проверенного снимка. Сценарий чужого удара также сохранён в `EngineControlTests.ForeignCollisionAtLanding`.

Локальный приоритет landing исключает только собственный камень из соответствующего collision-события. Успех не добавляет камень в `HitObstacleIds`. Guard схода касается только исходной trailing face; новые приземления вне метки проверяются снова. Связанный after-ring получает действительную устойчивую посадку как конец манёвра, а не требует старого фиксированного перелёта 0,8 с.

Отдельный engine-прогон на том же freeze сообщил **13 сценариев / 655 утверждений**, прежние V1/V2/V3/V4/TUNE и JS differential **40 228 snapshots / 1 448 208 полей** PASS. Они не входят в независимые 4 812. Runtime этим аудитом не изменялся.

## Воспроизведение

PowerShell 7, из корня Unity-проекта, в новом процессе. Для воспроизведения именно этого результата нужен указанный выше снимок Core; при последующих изменениях сравнить SHA и записать новый результат отдельно. Unity не запускается.

```powershell
$auditDir = Join-Path (Split-Path $PWD -Parent) ('.tmp-control-landing-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $auditDir | Out-Null
Get-ChildItem -LiteralPath ./Assets/Scripts/Core -Filter '*.cs' |
    Copy-Item -Destination $auditDir
Copy-Item -LiteralPath ./Verification/control-landing-independent.cs.txt -Destination (Join-Path $auditDir 'LandingProbe.cs')
$auditSources = @(Get-ChildItem -LiteralPath $auditDir -Filter '*.cs' | ForEach-Object FullName)
Add-Type -Path $auditSources
[ControlLandingIndependent]::Run()
```

Проверки синтетических контактов не заменяют browser gate, профильную геометрию и человеческое сравнение удобства управления.
