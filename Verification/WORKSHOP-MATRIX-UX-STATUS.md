## Решения

Astra/high: N — все клетки выбранного диапазона, в том числе ещё не вычисленные; доли стабильны по знаменателю во время расчёта. Зелёные = safe, красные = collision, серые = invalid. rejected/incomplete/pending отдельно; первые три доли не обязаны составлять 100%. Проба пропуска в N не входит. При отсутствии G+R перекрёстные доли отсутствуют, не нулевые. Фильтр темпа затемняет, но не меняет доли физических исходов. Числа характеризуют сетку локальных проб, не вероятность человеческого прохождения.

Автовыбор использует авторитетное состояние симуляции. Оба конца двухкомандного полёта открывают одну пару. Для трёх и более команд выбранная внутренняя точка открывает предыдущая→выбранная; остальные команды фиксированы. Не переносить через отклонённый промежуточный ввод и границу настоящей посадки. Отклонённый/недостигнутый ввод — объяснение.

Контракт: POST `/api/analysis-target`, ReplayRequest + обязательный inputIndex. Ответ `{kind:"pair"|"single"|"unsupported",inputIndex,firstInputIndex:null|number,message}`. 10 секунд/отмена, без изменения исходника.
