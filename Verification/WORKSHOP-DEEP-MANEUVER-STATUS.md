# Мастерская 0.5.25: глубокий анализ целого манёвра

20 ноября 2026. Реализовано и проверено. Ветка `experiment/workshop-analysis-0.5.17`, база `630074e` (0.5.24).

Источник — прямой запрос пользователя в этом чате: совместно перебрать все точки исходного воздушного манёвра; для каждой показать 25 смещений с долей безопасных допустимых сочетаний остальных точек. Уточнения пользователя: минимум 100 мс между нажатиями; прямой процент G/V без старой калибровки. По нажатию клетки показывать один полный безопасный пример, ближайший к исходной ленте по сумме абсолютных смещений. Реализация поручена после согласования алгоритма.

WORKSHOP намеренно меняется. Дизайн согласован после проверки Astra/high; реализация Backend и Web — Sol/high. Root интегрирует и выпускает. Области владения: Backend — C#/Tests; Web — Web/тесты; Root — версия вне Web, HTTP-проверки, документы и пакеты. Отдельный независимый review после интеграции.

## Инварианты и приёмка

- Состав манёвра фиксируется по исходной траектории; альтернативы могут менять число полётов и места посадки. Остальные команды не сдвигаются.
- Успех требует исполнения всех выбранных команд без удара, настоящей опоры после последней и прохождения X конца исходного манёвра. Ранняя посадка до препятствия не является достаточным успехом.
- Общая оценка — G/V уникальных сочетаний, а не среднее процентов клеток. Незавершённые результаты явно предварительные; исчерпание бюджета не записывается физическим неуспехом.
- Для клетки пример минимизирует сумму абсолютных смещений; ничьи разрешаются детерминированно. Выбор примера не меняет проценты остальных строк и исходный референс.
- Старые парные пакеты не считаются совместимым глубоким анализом. Геометрия и другие группы данных карты сохраняются.
- Проверки: N=1/2/3/4, граница 99/100 мс, нулевой знаменатель, физическое отклонение, совместная зависимость строк, точное продолжение/JSON, устаревание, безопасный пример, оба управления. Большие N не заменяются скрытой выборкой.

Пустая клетка №1−600 мс очищает наложение и показывает отсутствие вариантов; просмотр не изменяет JSON. Редактирование ленты скрывает неактуальную панель. Проверены сохранение неполного шестикомандного расчёта в браузерном черновике, восстановление и продвижение курсора после перезагрузки. ## Ограничения

Полный перебор экспоненциальный; никаких скрытых случайных выборок или замены N соседними парами. Хранятся агрегаты и один ближайший пример для каждой клетки, а не все 25^N траекторий. Предварительные доли не включаются в итоговую числовую статистику готовых манёвров. Ограничение карты 2 МиБ и декодированного одного результата 1 МиБ сохранено. Подготовка/одна физическая проба имеют защитный лимит 10 секунд; при отсутствии продвижения цикл останавливается с сохранённым курсором. Пример проверяется локально до опоры/исходногоX, не до финиша всей трассы. Импортированные примеры проходят структурную проверку, физическая безопасность подтверждается повторно перед показом.
