## Контракт трёх вариантов

| Вариант | Контракт |
|---|---|
| A — линейный | Нынешний обычный перелёт 0,8 с; нужен как точка сравнения |
| B — гравитация | Первое нажатие меняет направление притяжения; старт с нулевой поперечной скоростью, обычный перелёт 0,8 с; повтор в воздухе не действует |
| C — гравитация + повтор | Один воздушный переворот ускорения при неизменной текущей скорости; следующий до правильной посадки не действует |

Начальная настройка B/C: путь центра 212 единиц, ускорение 662,5 единицы/с². При касании противоположной притяжению поверхности скорость обнуляется у границы, притяжение уводит обратно, способность не восстанавливается. Правильная посадка останавливает поперечную скорость и восстанавливает повтор. Удар замораживает состояние на 0,5 с, но не выдаёт повтор.

Свободное положительное кольцо подтверждается контактом сразу. Связанное с камнем остаётся неподтверждённым до чистого окончания манёвра и выхода из опасной области; возврат на исходную поверхность тоже допустим. Плюс/минус дают реальные −0,3/+0,3 с, сохраняется полный FIFO-эффект каждого кольца. Радиус героя и видимая позиция должны соответствовать используемой модели контакта.

## Независимый аудит физики: обязательные случаи

| Область | Проверка до статуса PASS |
|---|---|
| Кинематика | `y(t)=y0+v0·t+a·t²/2`, `v(t)=v0+a·t`; симметрия пола/потолка; обычный перелёт 0,8 с; промежуточное положение и скорость |
| Инерция | До/после повторного нажатия скорость одинакова, меняется только знак ускорения; ранний/высокий/поздний возврат; нет завершения по старому таймеру |
| Независимые числовые ориентиры | Повтор на 0,2 с возвращает на исходную поверхность на 0,682842712… с; на 0,4 с — на 1,365685425… с. Порог достижения противоположной поверхности до разворота: первое плечо √0,32 = 0,565685425… с |
| Поверхности и способность | Только посадка по направлению притяжения восстанавливает повтор; касание неверной поверхности, касательное касание в вершине, удар, кольцо и пауза этого не делают. Проверить границы события и серии одинаковых нажатий |
| Непрерывный контакт | Самый ранний контакт параболы с кольцом/моделью камня; вход и выход за один большой шаг; два прохода одной области; касание без пересечения; контакт в t=0 и ровно на horizon |
| Корни | Для кольца квадрат расстояния — полином четвёртой степени; двойной корень может не менять знак. Проверить экстремумы, близкие корни, вырожденное a=0 и численную устойчивость |
| Границы отрезков | Пересчитать траекторию после landing, окончания/начала эффекта, столкновения и восстановления. Горизонтальная скорость 110/220/330 должна учитываться в каждом отрезке, не заменяться базовой |
| Награды | Свободная награда не зависит от чужого камня; рискованная отменяется связанным ударом. Одинаковременные контакт/удар/подтверждение имеют определённый порядок. Повторное пересечение кольца не даёт вторую награду |
| FIFO и финиш | ++/−−/+−/−+, несколько контактов, очередь при ударе; реальное пересечение финиша и частичный эффект. На подготовленной пробе все заработанные эффекты успевают завершиться |
| Пауза и сброс | Сохраняются y, поперечная скорость, притяжение, использованный повтор, pending-награда и эффекты; реванш очищает забег, сохраняя выбранный вариант и героев |
| Шаг времени | 30/60/144 Гц, неравномерные и крупные шаги, разбиение перед/после контакта; NaN/Infinity/нулевой dt; одинаковые маршруты обоих игроков дают одинаковый результат |
| Восстановимость | После ошибок и slow остаётся исполнимый способ избежать следующего камня; проверка реальным движением с реакцией, не делением расстояния на базовую скорость |

Для свободного кольца при постоянных на отрезке `vx` и `a`, смещениях центра `dx/dy` и суммарном радиусе `R` контрольный полином:

```text
D(t) = (dx + vx*t)^2 + (dy + vy*t + a*t^2/2)^2 - R^2
коэффициенты t^4 … t^0:
a^2/4, a*vy, vx^2+vy^2+a*dy, 2*(dx*vx+dy*vy), dx^2+dy^2-R^2
```

Нельзя ограничиться поиском смены знака D(t) между кадрами: касательный контакт даёт двойной корень. Разбиение по критическим точкам и поиск первого корня должны проверяться независимыми аналитическими примерами. Модель контакта камня явно фиксируется отдельно; круговой контакт кольца не подменяется расширенным прямоугольником.

## Стартовый read-only аудит 3.0.1

В прежнем `RaceSimulation.cs` перелёт интерполируется линейно по `FlipElapsed/0.8`; вертикальные интервалы столкновения линейны, контакт кольца решает квадратное уравнение, а подтверждение after-ring ждёт остаток прежних 0,8 с. Все четыре допущения надо согласованно заменить или явно отделить для новых вариантов. Смена только анимации или формулы y оставит неправильные контакты/подтверждение.

Это ожидаемая точка изменения старой модели, не утверждение о дефекте 3.0.1. Независимый reviewer не меняет runtime; после готовности новой реализации добавляет фактические результаты, проверенные исходники и ограничения.
