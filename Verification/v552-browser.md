# Unity 5.5.2-trial — браузерная приёмка

7 ноября 2026. **PASS.** Каталитик проверил реальные кнопки и заезд через браузер без изменения скрытого состояния игры. `http://127.0.0.1:4184/` обслуживает `Builds/WebGL-v5.5.2-decay-settings-unpacked` — распакованный проверенный ZIP. Видимая версия 5.5.2-trial.
