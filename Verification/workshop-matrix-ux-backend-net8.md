# Workshop 0.5.19 — проверка серверного выбора анализа на .NET 8

Проверено в рабочей копии `experiment/workshop-analysis-0.5.17` на базе `ba0f199` с изменениями Workshop 0.5.19.

```powershell
dotnet run --project Tools/TrackWorkshop/Tests/TrackWorkshop.Tests.csproj
```

Полный прогон завершился с кодом `0`. Прошли 6516 проверок, включая 8 штатных трасс и 16 эталонов. Целевой запуск той же программы с аргументами `-- --analysis-target` прошёл 41 проверку. Они покрывают оба профиля, команды по времени и дистанции, выбранный разгон, одиночные и парные цели, выбор среди трёх команд, непринятые и недостигнутые команды, отмену и неизменность исходного списка.

В регрессионном сценарии FastFlip с командами `0.5`, `1.24` и `1.95` с герой сталкивается с препятствием, принимает вторую команду в воздухе после восстановления, приземляется на камень и сходит с него до третьей команды. При временном удалении проверки `FlightActive` после предыдущего нажатия целевой тест завершился с кодом `1`. Выбор третьей команды ошибочно возвращал пару со второй через посадку. После восстановления проверки выбор вернул одиночную цель, а полный прогон прошёл успешно.
