## Метод

Все маршруты выполняются через настоящие готовность, `Press` и `Advance`. Scheduler использует только верхнюю границу горизонтальной скорости 330: шаг до следующего ввода не больше `remainingX/330`, поэтому новая награда внутри шага не позволяет перескочить ввод. Он не вызывает production predictor событий, не использует clone/bisection из TrackProofControl и не подставляет состояние игрока.

Проверены **1/30, 1/60, 1/144, 0,317, 2,5 и 100 с**, оба назначения смешанных маршрутов верхнему/нижнему игроку, фактическая дистанция финиша и общий elapsed. На подготовленных маршрутах все полученные импульсы полностью обслужены, активный эффект и очередь пусты. `FinishTime` сравнивается с реальным достижением ленты, а не используется как единственное доказательство.

Каждый реальный landing timestamp из прогона воспроизведён с начала через те же действия. В момент контакта проверены настоящая плоскость камня, центр внутри `LandingWidth`, выдача награды, конкретная опора/заряд согласно направлению гравитации и отсутствие записи допустимого камня как удара. Для обычных сравнений допуск 3e−7; при replay контакта — 2e−5 после дополнительного шага 1e−8 с, чтобы округление timestamp не оставляло событие с другой стороны границы. Это не изменение геометрии runtime.

## Общий сравнительный участок

Длина **4620 / 21 с без эффектов**. Геометрия общая, массивы действий зависят от управления: два отмеченных камня H48/H92 на противоположных сторонах, быстрая тройка, один видимый отрицательный бонус и свободный instant перед финишем. LandingWidth=52; правильная посадка сразу даёт ускорение, а не прежний круговой сбор над камнем.

| Маршрут, каждый из четырёх режимов | Фактический результат обоих игроков |
|---|---|
| Без наград | **21,0 с / 0+ / 0− / 0 ударов** |
| Обе посадки и последний instant | **20,1 с / 3+ / 0− / 0 ударов**, все три — instant |
| Намеренная ловушка | **20,4 с / 3+ / 1− / 0 ударов** |
| Пропуск только последнего подбора | **20,4 с / 2+ / 0− / 0 ударов** |

Одинаковые маршруты дают точную ничью. В смешанных парах выигрывает реальный более быстрый маршрут: полный против safe, полного с ловушкой и пропуска только последнего бонуса. Проверены оба расположения победителя на экране.

Safe у Moderate, LinearAirFlip и Unlimited не использует воздушных повторов. У Jump второй тап входит в нормальный способ сменить стену. После последнего возможного горизонтального контакта с финальным instant остаётся **287 единиц**, больше **198**, необходимых для свежего полного boost. Дополнительно все фактические маршруты проверены на пустую очередь и полный учёт импульсов: один геометрический запас не используется как доказательство любой возможной накопленной очереди.

## Восстановление после реальной ошибки

Независимо воспроизведены четыре конкретных случая из geometry-proof, с изменением времени только одного действия; остальной prefix остаётся по дистанции. После первого удара номинальный маршрут прекращается. В каждом случае оба игрока имеют `Support=None` и уже израсходованный ограниченный повтор.

| Ошибка | Реальный hit: elapsed / X | Допустимый выход после остатка штрафа +150 мс реакции |
|---|---|---|
| Moderate ideal, ввод 0 +80 мс | 4,953033558 / 1089,667383 | Без нажатия до X2155 |
| Linear ideal, ввод 0 −160 мс | 4,978181820 / 1095,2 | Без нажатия до X2155 |
| Jump safe, ввод 3 +640 мс | 8,807748542 / 1937,704679 | Ещё 0,80 с, тап, второй через 0,15 с; достигнут X2679 |
| Jump ideal, ввод 5 +640 мс | 12,753203088 / 2937,704679 | Ещё 0,80 с, один тап; достигнут X3339 |

Время/координата совпали с независимым replay в 2e−5, все escape-нажатия приняты, цель за следующим расширенным препятствием реально достигнута без нового удара. Это **четыре частичных восстановления, не четыре дополнительных полных финиша**.

Read-only review `RecoveryProof.cs` подтвердил сохранение первого actual collision snapshot, учёт оставшегося штрафа и реакции, проверку доступности нажатий и обязательное достижение следующего `trailing+radius+1`. Собственный proof автора геометрии охватывает **138 конкретных collision-состояний**. Это конечная выборка одиночных ошибок, не гарантия для любых накопленных ошибок; у последнего препятствия следующего уже нет.

## Отдельные высотные проходы

Длина **2860 / 13 с**, четыре отверстия шириной 20 на X900/1200/1500/1800. Исходные промежутки чередуются `[4,126]` и `[114,236]`; допустимые интервалы центра с учётом радиуса — **[18,112]** и **[128,222]**. Общей безопасной постоянной высоты нет.

Независимо подтверждены **13 с / 0 ударов**, 12 действий, из них **8 воздушных**: каждая из четырёх групп содержит старт с опоры и два повтора до следующей устойчивой посадки. Это демонстрирует несколько смен тяги в одном полёте; между группами заряд/опора действительно восстанавливаются на стене.

Проверены вход и выход из полной расширенной горизонтальной полосы каждого gate, все точки ввода внутри неё и аналитические внутренние экстремумы параболы на участках постоянной тяги. Ни одна проверенная точка или экстремум не касается запрещённой границы. Каждое из 12 действий отдельно сдвинуто на **−45 и +45 мс реального elapsed**: все 24 маршрута завершились за 13 с без удара. Это не проверка одновременного сдвига всех нажатий.

Авторский proof дополнительно измерил минимальный интервал между действиями **0,328058 с** и границы по сетке 5 мс. Он и root сообщают общий **TrackProofControl --verify: 17 985 проверок**, включая comparison 3314 и 138 recovery-состояний; промежуточные печатаемые счётчики накопительные, их нельзя складывать как независимые наборы.
