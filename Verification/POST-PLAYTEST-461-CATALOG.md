# Каталог после плейтеста — 4.6.1-trial

20 октября 2026 года. Узкая проверка по `flip-race-post-playtest-2026-10-20.md`.

Активный каталог содержит четыре трассы в прежнем порядке: Длинные серии, Быстрые связки, Высотный поток, Каскад. Семь прежних проб остаются на отдельной странице. Геометрия, физика и исторические builders Dense/Waves не изменены.

## Изменения

- `Assets/Scripts/Core/TracksRhythm.cs`: активен только Каскад; публичные `RaceTracks.Get(string)` и `TracksRhythm.Get(string)` направляют старые Dense/Waves в Каскад. `RaceTracks.Get(int)` сохраняет индексы 0–3, а старые 4/5 и другие недействительные индексы направляет в Каскад.
- `Assets/Scripts/Presentation/FlightSettingsMenu.cs`: нормализация старого выбора при открытии меню и перед применением; общий чистый factory `CreateSelectedFlight` сохраняет физические настройки и обоих героев. Нажатие карточки по-прежнему меняет только черновой выбор.
- `Assets/Scripts/Presentation/FlipRaceGame.cs`: перед готовностью или реваншем устаревшая ссылка на трассу заменяется Каскадом. Текущий активный заезд этим условием не изменяется.

В 4.6.0 идентификатор или индекс трассы **не сохранялся в PlayerPrefs**: первый вход выбирал первую исходную трассу. Поэтому новая система сохранения трасс не добавлена. Миграция обслуживает прежние ссылки в состоянии игры/меню и публичные lookup API. Действительно сохраняемые ключи профиля, пользовательского набора и звука остаются прежними; их значения не перезаписываются этой правкой. Выбранные герои сохраняются внутри текущей сессии при применении и реванше.

## Проверка

```powershell
dotnet run --project Tools/PostPlaytestCatalogCheck/PostPlaytestCatalogCheck.csproj -c Release
```

**PASS — 1 825 проверок.** Новый инструмент вызывает production `FlightPointer`, `BeginFlightMenu`, factory из `ApplyFlightChoice`, `Act` и настоящий countdown Core. Проверены:

- точные четыре ID, текущие индексы и перенаправление старых ссылок/индексов;
- центры и края всех четырёх карточек при 568×320, 844×390 и 1280×720;
- отсутствие обработки бывших нижних слотов Dense/Waves;
- оба пресета и отдельный custom с нулём воздушных повторов, без потери скрытого собственного набора;
- все 16 пар героев, обе старые трассы и состояния готовности/финиша: один ввод всё ещё ждёт второго игрока, второй запускает countdown Каскада;
- доступность семи прежних проб и применение текущих четырёх трасс без автоматического старта.

ProjectReference компилирует все runtime Core/Presentation/Web C# с Unity managed API. Нативные PlayerPrefs, Awake/GUI и браузер этим .NET-инструментом не исполняются; проверка browser/release остаётся отдельной у root. `git diff --check` для трёх изменённых production файлов не выявил ошибок пробелов. Исторические отчёты 4.6.0 не перезаписаны.

Новые артефакты: `post-playtest-461-catalog-proof.txt`, `post-playtest-461-catalog-layout.json`. При 568×320 карточки: `[28,105,248,44]`, `[292,105,248,44]`, `[28,154,248,44]`, `[292,154,248,44]`.
