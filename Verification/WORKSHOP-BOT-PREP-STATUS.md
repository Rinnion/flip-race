# Мастерская 0.5 / игра 5.4.4 — подготовка авторской трассы для бота

5 ноября 2026, **PASS — поставка принята**. Прямой запрос пользователя: подготовка хорошего маршрута и автосохранение; главное — после импорта своей карты играть с ботом. Идеальный маршрут не требуется. База: мастерская 0.4 `7389537`, docs `1fe2b99`; game 5.4.3. Каталитик интегрирует в этом чате, специалисты Sol/high, игровые границы проверил editor_bot_scope Astra/high.

## Объём и сохранение

WORKSHOP/BOT/TRACKFILE/CONTROL/HIDDEN/REWARD/FINISH. Реальная физика и текущая вероятностная модель бота сохраняются; встроенные карты не менять. Один хороший совместимый чистый ориентир, не библиотека готовых исходов и не доказанный глобальный оптимум. Поиск ограничен ресурсами/временем и отменяем; отсутствие результата не означает непроходимость.

Для MVP сохраняется контракт бота: непустые нажатия, один собранный финишный рывок с полным эффектом, B>0, C>0 и допустимые вероятности B/C. Несовместимая карта получает конкретную причину. Для selected-hidden проверяются все5 предупреждений0,4..1,2; authored — заданные таймеры; без hidden проверки дедуплицируются. Доступные готовые профили проверяются отдельно, chosen-only не расширяется.

Исходный черновик не переписывается подготовкой. Результат — отдельный JSON с эталоном и заранее видимым новым ID для копии штатной карты. После изменения исходника/параметров результат устаревает. Импорт не считает хеш доказательством: конечная проверка Core и настоящего Мастера до включения BOT, порциями с возвратом UI. Кэш связан с фактическим содержимым/профилем. Ошибка проверки не разрешает BOT; корректная человеческая карта остаётся доступной.

Автосохранение: исходный текст включая ошибочный JSON, нажатия, профиль/ось/предупреждение/имя в текущем браузере. При старте явное восстановление или отказ, без молчаливого затирания. Ошибки хранилища сообщаются и не ломают редактор.

Проверки не обещают проходимость произвольной геометрии или интерес человеческой игры.

- [PreparationTests](../Tools/TrackWorkshop/PreparationTests/proof-results.json): 32 проверки; короткие новые карты без подсказки, плотные препятствия, обычный бонус и финиш, оба профиля, hidden, неподдержанные карты, отмена, повреждённая подсказка, изоляция параллельных запросов и ограничение HTTP-расчётов. - [Полная «Полоса уловок» без эталона и ручной подсказки](workshop-full-track-prep.json): один ограниченный запуск, 7 920 ед., новый ID; готово примерно за 3,4 с, чистый эталон 33,65 с, 7 обычных наград и финиш. Проверка настоящего Мастера пройдена. Это найденный хороший вариант, не доказанный максимум.
- Web: 30 тестов, включая 4 теста черновика; синтаксис JS и diff check. Серверная политика: по 77 проверок на .NET 8/10. [Независимое ревью](workshop-bot-prep-review.md): найденный HTTP 500 на повреждённой подсказке исправлен и покрыт тестом.
- В браузере IAB открыта `raw-custom-bonus.track.json` без нажатий/эталона. «Подготовить бота» нашла маршрут 4,904545 с; исходный текст и ручное `[]` остались без изменения. Скачанный UI-файл `prepared-custom-bonus.bot.track.json` импортирован через штатную кнопку в WebGL из итогового ZIP. Игра сообщила «Маршрут и Мастер проверены»; пять уровней бота доступны. Реальный Мастер финишировал за 4,90 с, +2 награды, 0 ударов; человек без ввода — 5,65 с, 1 удар. [Скриншот результата](workshop-05-game-bot.png).

В новой вкладке того же браузера появился выбор восстановления; восстановлен точный ошибочный текст, показана ошибка JSON. После возврата правильного текста подготовка снова работает. ## Известные границы

Ограниченный поиск может не найти существующий маршрут. Подготовка требует текущий контракт B/C и финишного рывка; неподдержанная карта остаётся человеческой. UI готовит выбранный профиль, API допускает два; карта не получает автоматически второй профиль. Импорт игры живёт только в текущей сессии, черновик — только в localStorage этого браузера/адреса. Индивидуальный учёт завершения каждого эффекта Мастера не добавлен: используется прежний агрегатный критерий, подробно описанный в статье BOT; точный эталон проверяется строже. Блокеров приёмки нет.
