# MODES-05 — браузерная проверка 4.5.0-trial

19 октября 2026. **PASS:** финальная Web-сборка, матрица двух профилей и трёх трасс, миграция/custom и два реальных заезда из распакованного ZIP. Проверки выполнены в desktop Chromium IAB с viewport 568×320 и 844×390. Это не физический телефон.

Сборка: `Logs/modes-final-build.log`, exit0, `Builds/WebGL-v4.5.0-final`, версия `4.5.0-trial`. Основной локальный адрес — [4184](http://127.0.0.1:4184/?v=4.5.0-trial). Сохранены [все 21 записи маршрутов](modes-browser-runs.json), [17 записей UI](modes-ui-browser.json) и [консоль](modes-browser-console.json): `final=[]`, `unpacked=[]` для warnings/errors. Номера ниже — позиции в массиве маршрутов, начиная с1. Частота диагностических снимков не является измерением FPS.

## Меню, миграция и custom

[UI trace](modes-ui-browser.json) подтверждает фактическую миграцию сохранённого старого active ID1 в Основной; старый custom `1|0|1|1|1000|140|400|265|112|0` сохранил все физические значения, сменив только reset metadata на10. Все прочие старые ID проверены codec-тестами, а не отдельными браузерными миграциями.

Проверены точные активные и неактивные поля Fast, его reload, сохранение custom после выбора/применения/reload Fast, применение и reload custom, фактический текст системного clipboard, ручной черновик и reset к Fast ID11 с восстановлением неактивных полей. Нажатие отключённого linear-поля не меняет Gravity-профиль. Изменение черновика не меняет активную физику до применения. Переключение трасс сохраняет Fast; применение возвращает ready без автоматического старта. [Меню568×320](modes-menu-568.png), [меню844×390](modes-menu-844.png), [редактор Fast](modes-editor-fast.png). Подробные параметры и границы: [MODES-UI.md](MODES-UI.md).

Финальный smoke основной игры подтвердил: смена своего героя сбрасывает свою готовность, сохраняет готовность другого, одинаковый герой разрешён. [Ready844×390](modes-final-ready-844.png). После сброса viewport override фактический размер656×1012 — portrait; постоянная версия видна, игра в ready. [Финальный portrait](modes-final-portrait.png). Это проверка ориентационного экрана/версии, не дополнительный заезд на телефоне.

Выбор героев, native input→next paint, startup и первые анимационные позы измерены отдельно в [MODES-LATENCY.md](MODES-LATENCY.md). Native Event Timing — браузерная метрика до следующего paint с округлением8мс, не точное физическое свечение экрана телефона.
