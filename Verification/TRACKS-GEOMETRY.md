Все имеют длину7920 и16 игровых манёвров, девять обычных положительных наград, две ловушки и отдельную финальную цель. Каждый полный маршрут собирает все девять обычных наград и финишную без ударов; обе половины симуляции дают точную ничью.

На каждой есть стандартная нижняя и верхняя посадки64×48, одна крупная200×92, before/after, два свободных мгновенных кольца, независимая цепочка из двух мгновенных колец. Кольца представлены в полосах Y≈200,120,60 и в зеркальных положениях. Неподвижный бег по стене не подбирает задуманные воздушные кольца автоматически.

Видимость локального манёвра проверена отдельным design-review: воздушные комбинации занимают не более308 world по направлению движения, цепочка208; это внутри1080 ahead минимального мобильного поля. Следующий самостоятельный манёвр после устойчивой опоры не приравнивается ко всей ритмической группе.

## Production-проверки

`--verify`: **14 158 checks PASS**. Все три маршрута каждой трассы, шесть dt до100с; каждое отдельное безопасное нажатие с отклонением±60мс; полная очередь отрабатывает до финиша. Для authored safe/full/negative отдельно проверено, что непосредственно в X7876 нет активных/ожидающих обычных эффектов или неподтверждённых наград.

`--windows`: измеренные непрерывные локальные окна полного сбора на сетке5мс, ограничение поиска150мс. Минимум в обе стороны: Long±30мс, Short±45мс, Flow±30мс. Это отдельный сдвиг одного нажатия при сохранении остальных дистанционных действий, не гарантия произвольной накопленной ошибки всех действий.

`--recovery`: **195 реальных состояний столкновения** из safe/full маршрутов при сдвигах±.16/.32с: Long34/36, Short32/40, Flow24/29. После окончания recovery и ещё150мс реакции найден выход без следующего удара через удержание либо один/два реальных Press. Это конечная выборка ошибок, а не доказательство всех возможных историй.

Независимый аудит delivery проверяет маршруты, асимметричную финальную награду и собственную выборку recovery отдельно. Не смешивать его счёт с основным.

## Воспроизведение и экспорт

Из корня проекта, .NET10; Unity не нужна:

```powershell
dotnet run --project Tools/TrackProofFull/TrackProofFull.csproj -- --stage1
dotnet run --project Tools/TrackProofFull/TrackProofFull.csproj -- --verify
dotnet run --project Tools/TrackProofFull/TrackProofFull.csproj -- --windows
dotnet run --project Tools/TrackProofFull/TrackProofFull.csproj -- --recovery
dotnet run --project Tools/TrackProofFull/TrackProofFull.csproj -- --routes
```

- [tracks-routes.json](tracks-routes.json): точные distance-массивы safe/full/negative, фактические время/опора/высота каждого полного нажатия, препятствия и зоны.
- [tracks-windows.json](tracks-windows.json): локальные ранние/поздние окна каждого полного нажатия.
- [tracks-proof.txt](tracks-proof.txt): основной stdout.
- Runner использует настоящие Press/Advance и общий snapshot/actual-speed scheduler TrackProofControl; физическое состояние для authored маршрутов не подставляется.
