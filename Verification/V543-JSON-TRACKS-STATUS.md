## Объём первого этапа

Восемь действующих полных трасс становятся данными JSON. В WebGL встроенные файлы загружаются по относительным URL из каталога рядом со сборкой. Пользователь импортирует отдельный JSON через выбор файла на компьютере/телефоне. Оба источника используют один формат и проверку. Встроенные трассы и 15 подготовленных сочетаний с ботами сохраняют прежнее поведение.

Визуализатор, перетаскивание, поиск нового бот-ориентира, новые механики и произвольная сетевая библиотека в этот этап не входят. Новые пользовательские карты не получают устаревший бот-эталон только из-за совпавшего ID. Поддержка формата версионируется; неизвестные игровые типы не игнорируются. Инструкция Markdown описывает реально выпущенные пути загрузки.

Сохраняемые ID: GATE, HIDDEN, REWARD, FINISH, CONTROL, BOT, SOLO, VIEW, TOUCH. Геометрия, физика, обе части ворот, общий таймер скрытых блоков, профили, награды и вероятности ботов не меняются.
