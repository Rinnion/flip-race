- Независимые готовые маршруты: **21 684 утверждения / 234 полные игры и 4 частичных recovery-replay** — [исходник](control-finish-geometry-independent.cs.txt), [stdout](control-finish-geometry-independent.txt).
- Авторский TrackProofControl: **20 451 проверка**, включая прежние 138 recovery-состояний; [метод и ограничения](../Tools/TrackProofControl/REPORT.md).
- EngineFinishTests: **10 сценариев / 1 598 утверждений**. Отдельный authored asymmetric stress: **1 518 / 24 игры**. Эти числа не складываются как уникальные физические случаи.

Предыдущий [геометрический аудит 4.2.0](CONTROL-GEOMETRY-AUDIT.md) и его harness сохранены без подмены результатов. Ранние browser-заезды со временем 20,1 с относятся к прежнему финальному instant, не к новому рывку.

## Контракт и независимые oracle

Финишный подбор проверяет пересечение **центром плоскости X4576**, за 44 единицы до ленты X4620. Допустимый центр по Y — **[52,68]**, высота 16. Радиус игрока/кольца не расширяет это окно. Отдельная скорость **440** действует до физического финиша. На чистом подходе 220 последние 44 занимают **0,1 с вместо 0,2 с**: преимущество ровно **0,1 с**.

Награда не добавляет обычный импульс 0,6 с и не меняет вертикальную скорость, тягу или очередь. Отдельные `FinishBoostsEarned`, `FinishBoostElapsed` и `FinishBoostDistanceGained` сохраняются для результата; активный флаг выключается на финише и всё сбрасывается при реванше. Обычные landing-награды остаются прежними.

Все независимые игры создаются через штатные готовность, `Press` и `Advance`, без подстановки динамического состояния. Проверены четыре управления и шаги **1/30, 1/60, 1/144, 0,317, 2,5 и 100 с**. Scheduler маршрутов ограничивает следующий шаг величиной `remainingX/440`, поэтому новая награда внутри шага не позволяет перескочить запланированный ввод. Он не вызывает production predictor, clone или bisection из авторского proof.

Физические fixtures проверяют включённые Y-endpoints и промахи на 1e−6 снаружи, отсутствие раннего подбора даже с Radius999, движущийся центр, оба назначения победителя, точную ничью, t=0, одноразовость, второй finish-объект, уже пройденную/послефинишную плоскость, столкновение одновременно с подбором, freeze во время восстановления и полный reset. Реальные elapsed и дистанция ленты проверяются отдельно от канонического `FinishTime`.

Синтетический dirty-entry намеренно оставляет активные ordinary boost/slow и противоположный импульс в очереди. Независимый кусочный oracle интегрирует дополнительную дистанцию `440 − ordinarySpeed` по обе стороны окончания ordinary-эффекта. Физический и канонический финиш совпадают; необслуженная очередь не стирается ради результата. Чистая авторская трасса не зависит от этой дополнительной устойчивости к синтетическому состоянию.

## Чистый подход при любом достижимом наборе наград

На общем участке до finish имеются только **две одноразовые landing-награды и один отрицательный бонус**. Нет linked-награды с отложенным подтверждением. Последний возможный ordinary-контакт — X**3132**: 3110 + радиус бонуса 8 + радиус игрока 14. Метки посадки заканчиваются раньше.

Отсюда до плоскости остаётся **1444 единицы**, то есть минимум **1444 / 330 = 4,375758 с движения** при самой высокой ordinary-скорости. Все три возможных импульса вместе требуют не более **1,8 с обслуживания**. Проверены все восемь подмножеств. Даже если вся эта очередь ещё не обслужена на X3132, она закончится задолго до X4576. Recovery одновременно замораживает движение и обслуживание и не нарушает неравенство. Обнуление честно заработанных эффектов не требуется.

Дополнительно в реальных ideal/trap-заездах timestamp финишного подбора воспроизведён с начала: за 1e−8 с до плоскости скорость 220, active/queue пусты и все ordinary-награды полностью обслужены; после пересечения скорость 440 и центр внутри узкого окна. Так же повторно проверены обе реальные landing-плоскости, опоры и отсутствие ложного удара.

## Фактические маршруты

| Общий участок, каждый из четырёх режимов | Время | Ordinary / finish / negative / hits |
|---|---:|---|
| Без наград | **21,0 с** | 0 / 0 / 0 / 0 |
| Две посадки и точный финиш | **20,3 с** | 2 / 1 / 0 / 0 |
| Те же награды и видимая ловушка | **20,6 с** | 2 / 1 / 1 / 0 |
| Пропущен только последний рывок | **20,4 с** | 2 / 0 / 0 / 0 |

Смешанные дуэли проверены в обоих назначениях игрокам и на всех шести шагах. В паре 20,3 против 20,4 с именно последний подбор определяет победителя; одинаковые маршруты дают точную ничью. У получившего финишный рывок фактическая длительность 0,1 с и дополнительная дистанция 22; ordinary-счётчик остаётся равным двум.

Последний ввод по дистанции: Moderate/Unlimited **4523,152127406574**, Linear **4537,811320754717**, Jump **4547,531146724642**. Независимо проверен отдельный сдвиг только этого ввода на **±25 мс** (Moderate/Jump/Unlimited) или **±30 мс** (Linear) реального elapsed. Это не гарантия одновременной ошибки всех нажатий. Более подробные окна авторского proof измерены по сетке 1 мс.

Повторены четыре прежних фактических recovery-witness и отдельный unlimited-участок: **13 с / 0 ударов, четыре прохода / 12 действий, из них 8 воздушных**. Для проходов проверены расширенные границы, аналитические внутренние экстремумы параболы и каждый input отдельно ±45 мс. Частичные recovery-replay доказывают достижение цели за следующим препятствием, а не полную восстановимость любых накопленных ошибок.

## Исправленная граница ожидания второго игрока

При асимметричном authored-заезде engine обнаружил остановку на `23,799999999178137` вместо точного deadline 23,8: игрок оставался на 1,805e−7 единицы до ленты. Причина — `ResolveFinish` завершал игру на `WinnerAt + FinishGrace − Epsilon`, хотя внешний `Advance` уже ограничивает шаг точным deadline.

Финальная правка убирает только это преждевременное `− Epsilon`; допуски геометрии и ничьей не меняются. Read-only review подтвердил согласованность с обработкой положительных субнаносекундных шагов. Engine проверил все четыре режима, обе половины и 144 Гц / 0,317 / 100 с: финиш второго игрока **ровно 23,8** сохраняется. Отдельный действительно опоздавший участник по-прежнему останавливается без финиша. Все независимые наборы этого отчёта повторены после правки.

Root повторил на окончательном Core suites V1 **963**, V2 **3554**, V3 **865**, V4 **1770**, TUNE **1009**, CONTROL **2165**, CONTROL-03F **1598**; JS differential **40 228 snapshots / 1 448 208 полей** — PASS.
