# 4.5.1-trial — браузер: один повтор и сохранение custom

19 октября 2026. **Целевые браузерные проверки PASS:** обновление сохранений, новый FastFlip с одним повтором, независимый ввод игроков, версия у названия и безопасный заезд из распакованного ZIP. Сборка и статическая проверка архива описаны в [FLIP451-RELEASE.md](FLIP451-RELEASE.md).

Проверено в desktop Chromium IAB с viewport 844×390 и 568×320. [Исходный журнал](flip451-browser.json) сохранён целиком: миграция, шесть событий свободного полёта, обе попытки полного маршрута и отдельный заезд из архива. Диагностические снимки не являются измерением FPS.

## Обновление и настройки

Реально обновлён один и тот же origin `http://127.0.0.1:4197/` с 4.5.0 до 4.5.1, сохранив browser storage. До обновления активный Fast имел 0 повторов; после загрузки 4.5.1 готовый ID 11 получил One. Ранее явно сохранённый custom с 0 остался с 0, затем был применён и повторно проверен после reload.

Edit из Fast создаёт черновик с One. Ручное изменение черновика на None и последующий Reset к Fast возвращают One; это значение сохраняется после reload. Прежние физические поля 2700 / 35 / 300 / 530 / 112 не изменены. Сохранение custom означает отсутствие автоматической замены его параметров при выборе готовой кнопки; намеренное редактирование/Reset по-прежнему сохраняет пользовательский черновик.

## Реальные A/L в свободном полёте

Запись `real browser single repeat and independent players` подтверждает:

1. Первый тап начинает полёт с опоры, заряд воздушного повтора доступен.
2. Первый воздушный повтор меняет направление тяги и расходует заряд; движение продолжается с текущей вертикальной скоростью.
3. Следующий воздушный тап до восстановления заряда не меняет направление повторно.
4. Нижний игрок управляется отдельно; ввод верхнего не расходует его заряд.
5. Настоящая посадка на стену восстанавливает заряд; в следующем полёте повтор снова доступен.

Точное сохранение VY на момент принятия ввода и отклонение второго повтора дополнительно проверены целевыми Core-тестами через Press/Advance. Браузерные снимки публикуются дискретно и не выдаются за измерение каждого физического микрошага.

## Маршруты и честное ограничение финального бонуса

| Запуск | Артефакт / viewport | Результат обоих игроков |
|---|---|---|
| Fast / Быстрые связки, full, попытка 1 | Финальный Web / 844×390; 18 действий, без пауз | **33,3 с, 9 обычных наград, 0 ударов, 0 минусов, 0 финальных бонусов** |
| Fast / Быстрые связки, full, попытка 2 | Тот же Web / 844×390; 18 действий, без пауз; последний целевой ввод сдвинут на −45 мс | **33,3 с, 9 обычных наград, 0 ударов, 0 минусов, 0 финальных бонусов** |
| Fast / Быстрые связки, safe | `Builds/WebGL-v4.5.1-unpacked` / 568×320; 4 действия, без пауз | **36,0 с, 0 наград и 0 ударов** |

Обе full-попытки сохранены без подмены успешным запуском. Сбор девяти обычных наград в браузере подтверждён; узкая финальная цель в этих попытках **не взята**. Поэтому браузерный full за 33,2 с для 4.5.1 не заявляется. Такой результат подтверждён исполняемым Core-стендом с точным расписанием ввода; он не заменяет отсутствующий браузерный исход. Эти попытки показывают предел точности данного нативного расписания ввода, а не измеренное человеческое окно. Новое исследование окон этим узким релизом не проводилось.

## Версия и распакованный архив

Номер `4.5.1-trial` постоянно виден рядом с названием в проверенных состояниях: [ready 568×320](flip451-version-568.png), [меню 568×320](flip451-version-menu-568.png), [пауза 844×390](flip451-version-pause.png), [финиш 844×390](flip451-version-finish.png), [desktop 1280×800](flip451-version-desktop.png) и [portrait 390×844 с rotation overlay](flip451-version-portrait.png).

Распакованная копия реально загружена с тестового адреса `http://127.0.0.1:4198/`. В raw есть `unpacked ZIP ready at568x320`, а safe-заезд помечен `artifact="Builds/WebGL-v4.5.1-unpacked"`. Это отдельная проверка именно файлов из ZIP. Все 5 SHA, корневой index, относительные ресурсы и WASM совпали [при независимой распаковке](flip451-package-verification.json). Тестовые origin 4197/4198 не являются постоянными адресами поставки.

Основная игра [на 4184](http://127.0.0.1:4184/?v=4.5.1-trial) загружена с версией 4.5.1 и штатным неизменённым Основным профилем; финальная консоль errors пуста. [Финальный основной экран 1280×720](flip451-version-final.png). Viewport override сброшен, вспомогательные QA-вкладки закрыты. Физический телефон, native multitouch, мобильная производительность и itch.io iframe не проверены. Публикации нет. Браузерный scope этой версии — целевой повтор, сохранения и перечисленные маршруты, а не новый полный прогон всех шести сочетаний профиля и трассы.
